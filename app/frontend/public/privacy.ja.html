プライバシーポリシー

最終更新日: 2026年6月20日

はじめに

Atlasphere（「当社」「私たち」）は、ユーザー（「あなた」）のプライバシー保護に努めます。本ポリシーは、Pi Network 上の当社分散型ガバナンスプラットフォームを利用する際に、個人データをどのように収集、利用、保護するかを説明します。

収集するデータ

当社が収集するデータは以下の通りです：

  • 認証時の Pi Network 識別子（UID）およびユーザー名
  • プラットフォーム上の投票履歴、提案、寄付
  • クエスト進行データおよび評価スコア
  • 言語設定とインターフェース設定

データの利用目的

あなたのデータは以下の目的で使用されます：

  • Pi Network SDK を通じた本人確認
  • 投票、提案、金銭的寄付の管理
  • 評価スコアと投票ウェイトの算出
  • コミュニティクエストの進捗追跡
  • プラットフォームの改善と体験のパーソナライズ

Pi 取引

Pi 取引は公式の Pi Network SDK を介して処理されます。透明性確保のため、支払額とステータスを記録しますが、プライベートキーは一切保存しません。

データの共有

個人データを第三者に販売または共有することはありません。投票や寄付はガバナンスの透明性確保のため、プラットフォーム上で公開されます。認証のために Pi 識別子が Pi Network と共有されることがあります。

セキュリティ

当社は、転送時の暗号化や安全な Pi Network 認証など、合理的なセキュリティ対策を実施しています。

あなたの権利

適用法に基づき、個人データへのアクセス、訂正、エクスポート、削除を要求することができます。

クッキーとローカルストレージ

Atlasphere はローカルストレージを使用して言語設定や認証セッションを保存します。第三者によるトラッキングクッキーは使用していません。

お問い合わせ

プライバシーに関する質問は、Pi Network プラットフォームまたはコミュニティサポートチャンネルを通じて Atlasphere にお問い合わせください。
