آخر تحديث: 20 يونيو 2026

مقدمة

Atlasphere ("نحن"، "لنا") ملتزم بحماية خصوصية مستخدميه ("أنت"). تصف هذه السياسة كيف نجمع، نستخدم، ونحمي بياناتك الشخصية عندما تستخدم منصتنا اللامركزية للحكم على شبكة Pi Network.

البيانات التي تم جمعها

نقوم بجمع البيانات التالية:

  • معرف شبكة Pi (UID) واسم المستخدم أثناء المصادقة
  • سجل التصويت، المقترحات، والمساهمات على المنصة
  • بيانات تقدم المهام ونقطة السمعة
  • تفضيلات اللغة وإعدادات الواجهة

استخدام البيانات

يتم استخدام بياناتك لـ:

  • مصادقة هويتك عبر Pi Network SDK
  • إدارة أصواتك، مقترحاتك، ومساهماتك المالية
  • حساب نقطة السمعة ووزن التصويت الخاص بك
  • متابعة تقدمك في مهام المجتمع
  • تحسين المنصة وتخصيص تجربتك

معاملات Pi

يتم معالجة معاملات Pi عبر Pi Network SDK الرسمي. نسجل مبالغ الدفعات وحالاتها لضمان شفافية تمويل المجتمع. لا نقوم أبداً بتخزين مفاتيحك الخاصة.

مشاركة البيانات

نحن لا نبيع أو نشارك بياناتك الشخصية مع أطراف ثالثة. الأصوات والمساهمات مرئية للجمهور على المنصة لضمان شفافية الحوكمة. قد يتم مشاركة معرف Pi الخاص بك مع شبكة Pi للمصادقة.

الأمان

نستخدم تدابير أمان معقولة، بما في ذلك التشفير أثناء النقل ومصادقة Pi Network الآمنة.

حقوقك

يمكنك طلب الوصول إلى بياناتك الشخصية أو تصحيحها أو تصديرها أو حذفها، وفقاً للقانون المعمول به.

ملفات تعريف الارتباط والتخزين المحلي

تستخدم Atlasphere التخزين المحلي لحفظ تفضيلات اللغة وجلسة المصادقة الخاصة بك. لا يتم استخدام ملفات تعريف ارتباط تتبع من أطراف ثالثة.

الاتصال

تواصل مع Atlasphere عبر منصة Pi Network أو قناة دعم المجتمع لأسئلة الخصوصية.
