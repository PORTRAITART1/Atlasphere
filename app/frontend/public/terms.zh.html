服务条款

最后更新：2026年6月20日

接受条款

通过访问和使用 Atlasphere，您同意受本服务条款的约束。如果您不接受这些条款，请勿使用本平台。

服务描述

Atlasphere 是一个基于 Pi Network 的去中心化治理平台，允许先锋们：

  • 提交社区项目提案
  • 使用加权声誉系统对提案进行投票
  • 以 Pi 为单位为获批项目提供资金
  • 参与任务以获取奖励
  • 在社区内建立声誉

资格要求

您必须拥有已验证的 Pi Network 账户才能使用 Atlasphere。您必须在所在司法辖区达到法定年龄，方可签订具有约束力的协议。

用户账户

您的账户与您的 Pi Network 身份关联。您有责任维护 Pi 账户的安全。通过您的账户进行的任何活动均由您负责。

行为准则

使用 Atlasphere，即表示您同意：

  • 不提交非法、冒犯性或误导性内容
  • 不操纵投票或声誉系统
  • 不创建虚假提案以转移资金
  • 尊重其他社区成员
  • 不使用未经授权的机器人或自动化工具

Pi 交易

Pi 捐赠是自愿的，并通过官方 Pi Network SDK 完成。已确认的交易不可逆转。Atlasphere 对 Pi 价值波动不承担责任。

知识产权

提交的提案仍归其作者所有的知识产权。提交提案即表示您授予社区在提案获批后用于项目实施的使用许可。

责任限制

Atlasphere 按“原样”提供。我们不保证已资助项目的成功或投资回报。平台不对与 Pi 交易或社区项目相关的损失承担责任。

治理

投票结果遵循平台公布的声誉和治理规则。除非平台提供申诉程序，否则封闭式治理决策为最终决定。

暂停与终止

因欺诈、滥用、违反本条款或对社区有害的行为，访问可能被暂停。

修改

我们可能会更新本条款，并通过平台发布更改。发布后继续使用即视为接受。

联系

如有疑问，请通过 Pi Network 平台或社区支持渠道联系 Atlasphere。
