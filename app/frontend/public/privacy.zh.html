隐私政策

最近更新：2026年6月20日

介绍

Atlasphere（“我们”）致力于保护其用户（“您”）的隐私。本政策描述了当您在 Pi Network 上使用我们的去中心化治理平台时，我们如何收集、使用和保护您的个人数据。

收集的数据

我们收集以下数据：

  • 在身份验证期间的 Pi Network 标识符（UID）和用户名
  • 平台上的投票历史、提案和贡献
  • 任务进度数据和声誉评分
  • 语言偏好和界面设置

数据使用

您的数据用于：

  • 通过 Pi Network SDK 验证您的身份
  • 管理您的投票、提案和财务贡献
  • 计算您的声誉评分和投票权重
  • 跟踪您在社区任务中的进度
  • 改进平台并个性化您的体验

Pi 交易

Pi 交易通过官方 Pi Network SDK 处理。我们记录付款金额和状态，以确保社区资金的透明度。我们永不存储您的私钥。

数据共享

我们不会出售或与第三方共享您的个人数据。投票和贡献在平台上公开可见，以确保治理透明度。您的 Pi 标识符可能会与 Pi Network 共享用于身份验证。

安全

我们采用合理的安全措施，包括传输中的加密和安全的 Pi Network 身份验证。

您的权利

您可以根据适用法律请求访问、更正、导出或删除您的个人数据。

Cookie 与本地存储

Atlasphere 使用本地存储来保存您的语言偏好和身份验证会话。未使用第三方跟踪 Cookie。

联系

如有隐私问题，请通过 Pi Network 平台或社区支持渠道联系 Atlasphere。
