**Atlasphere** est la première plateforme de gouvernance décentralisée et de financement participatif construite par et pour les Pionniers Pi Network. Elle combine DAO, EcoChain AI, gamification et paiements Pi natifs.

1. **Community-First** — Gouvernance par les Pionniers, pour les Pionniers
2. **Pi-Native Payments** — Paiements Pi intégrés (U2A + escrow + milestones)

# 🗺️ FEUILLE DE ROUTE — DU MARKETING AU MAINNET

## Phase M1 : Préparation (Semaine 1-2)
- [ ] Finaliser le pack marketing (images, bannières, textes) ✅
- [ ] Créer les comptes sociaux Atlasphere (Twitter/X, Telegram, Discord)
- [ ] Configurer le formulaire de feedback in-app (déjà fait ✅)
- [ ] Préparer le tracking analytics (nombre de testeurs, actions, feedback)
- [ ] Vérifier que l'app fonctionne parfaitement en sandbox Pi Browser
- [ ] Tester le flux complet : auth → vote → payment → quest → feedback

## Phase M2 : Lancement Beta Privée (Semaine 3-4)
- [ ] Poster sur Fireside (message FR ci-dessus)
- [ ] Poster sur Corptime/Corpfm (message FR ci-dessus)
- [ ] Inviter 50 Pionniers "ambassadeurs" pour test initial
- [ ] Collecter les premiers retours et corriger les bugs critiques
- [ ] Atteindre 100 testeurs actifs
- [ ] Documenter les métriques : sessions, votes, paiements sandbox

## Phase M3 : Lancement Beta Publique (Semaine 5-8)
- [ ] Diffuser dans les chats communautaires Pi (message FR ci-dessus)
- [ ] Publier l'annonce "Appel aux Pionniers" (message FR ci-dessus)
- [ ] Activer le système de parrainage (/referral) pour croissance virale
- [ ] Poster les bannières sur les réseaux sociaux Pi
- [ ] Organiser un "Test Day" communautaire (objectif : 200 testeurs en 24h)
- [ ] Atteindre 500 testeurs actifs
- [ ] Publier un rapport de feedback public (transparence)

## Phase M4 : Croissance & Preuve d'Adoption (Semaine 9-12)
- [ ] Atteindre 1000+ testeurs actifs
- [ ] Collecter 100+ feedbacks structurés
- [ ] Publier des témoignages de Pionniers (screenshots, citations)
- [ ] Créer une vidéo démo de 2 minutes (fonctionnalités clés)
- [ ] Organiser un AMA (Ask Me Anything) sur Fireside
- [ ] Documenter les métriques d'engagement (DAU, votes/jour, Pi transférés)

## Phase M5 : Préparation Candidature Mainnet (Semaine 13-14)
- [ ] Compiler le dossier de candidature :
  - Description de l'app et proposition de valeur
  - Métriques d'adoption (testeurs, engagement, rétention)
  - Preuves de conformité Pi SDK (auth, payments, PiRC2)
  - Documentation technique (API, sécurité, architecture)
  - Feedbacks communautaires positifs
  - Plan de monétisation (abonnements, marketplace, eco-ads)
- [ ] Vérifier la checklist technique Mainnet :
  - ✅ Pi SDK v2.0 intégré (init → authenticate → payments)
  - ✅ Backend valide tokens via GET /v2/me
  - ✅ Payments U2A avec approve/complete
  - ✅ onIncompletePaymentFound géré
  - ✅ PiRC2 subscriptions intégrées
  - ✅ Pas de clé API Pi exposée côté client
  - ✅ sandbox: false configurable pour production
- [ ] Faire un audit sécurité final
- [ ] Switch sandbox → production dans les settings

## Phase M6 : Soumission Mainnet (Semaine 15-16)
- [ ] Soumettre la candidature sur Pi Develop Portal
- [ ] Répondre rapidement aux questions de l'équipe Pi
- [ ] Continuer à faire croître la base utilisateurs pendant la review
- [ ] Préparer le plan de lancement Mainnet (migration données, annonce)

## Phase M7 : Post-Acceptation (Semaine 17+)
- [ ] Annonce officielle à la communauté
- [ ] Activer les paiements Pi réels (mainnet)
- [ ] Lancer la campagne "Mainnet Launch" avec nouvelles bannières
- [ ] Activer les fonctionnalités premium (abonnements Pi réels)
- [ ] Célébrer avec la communauté ! 🎉
