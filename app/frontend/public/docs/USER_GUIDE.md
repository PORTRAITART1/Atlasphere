# 📖 Guide Utilisateur Atlasphere

## Premiers Pas

### 1. Connexion avec Pi Network

1. Ouvrez Atlasphere dans le **Pi Browser**
2. Cliquez sur **"Connecter avec Pi"** dans la barre de navigation
3. Autorisez l'accès à votre compte Pi (username + payments)
4. Vous êtes connecté ! Votre @username apparaît dans la navbar

### 2. Explorer les Propositions

- Allez sur **Propositions** dans le menu
- Filtrez par catégorie (Éducation, Tech, Environnement, Commerce, Santé)
- Filtrez par statut (En vote, En financement, Financé, Complété)
- Utilisez la **recherche globale** (🔍) pour trouver un projet spécifique

### 3. Voter sur un Projet

1. Ouvrez une proposition en statut "En vote"
2. Lisez la description, le budget, et l'équipe
3. Cliquez **👍 Pour** ou **👎 Contre**
4. Votre vote est pondéré par votre **réputation** (plus de réputation = plus d'influence)
5. Le projet est approuvé si : quorum atteint (5%) + 66% de votes "Pour"

### 4. Financer un Projet

1. Allez sur **Financement** ou ouvrez un projet approuvé
2. Choisissez le montant en π à contribuer
3. Confirmez le paiement via Pi SDK
4. Les fonds sont verrouillés en **escrow** jusqu'à validation des milestones

### 5. Soumettre un Projet

1. Cliquez **"Créer un Projet"**
2. Remplissez : titre, description, catégorie, budget, région
3. Ajoutez des milestones (étapes avec montants)
4. Utilisez l'**Assistant IA** pour améliorer votre proposition
5. Soumettez — votre projet passe en phase de vote

### 6. Système de Réputation

Votre réputation augmente quand vous :
- 🗳️ Votez sur des projets (+10 rep/vote)
- 💰 Financez des projets (+20 rep/contribution)
- 📋 Soumettez des projets approuvés (+100 rep)
- 🔥 Maintenez une série de jours actifs (streak)
- 🏆 Complétez des quêtes

**Niveaux** : Bronze → Silver → Gold → Diamond → Platinum

### 7. Quêtes & Récompenses

- Allez sur **Quêtes** dans le menu
- Complétez des objectifs quotidiens, hebdomadaires, ou uniques
- Réclamez vos récompenses (réputation + badges + Pi)

### 8. Délégation de Votes

- Allez sur **Délégation**
- Déléguez votre pouvoir de vote à un autre Pionnier de confiance
- Révoquez à tout moment
- Consultez l'historique de vos délégations

### 9. Carte Interactive

- Allez sur **Carte** pour voir les projets géolocalisés
- Filtrez par catégorie ou statut
- Cliquez sur un marqueur pour voir les détails

## FAQ

**Q: Mes Pi sont-ils en sécurité ?**
R: Oui, les fonds sont verrouillés dans un smart contract escrow PiRC2. Ils ne sont libérés que lorsque les milestones sont validés par la communauté.

**Q: Puis-je récupérer mes Pi si un projet échoue ?**
R: Oui, si la deadline est dépassée sans complétion, un remboursement proportionnel automatique est déclenché.

**Q: Comment augmenter mon poids de vote ?**
R: Participez activement ! Votez, financez, proposez des projets, et complétez des quêtes pour augmenter votre réputation.

**Q: L'app fonctionne-t-elle hors Pi Browser ?**
R: L'app est accessible en mode lecture, mais l'authentification et les paiements nécessitent le Pi Browser.
