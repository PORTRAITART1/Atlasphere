# Project Summary

Atlasphere est une plateforme communautaire pour les projets de l’écosystème Pi Network. Les Pioneers peuvent découvrir des initiatives, les financer en Pi et participer à leur gouvernance, tout en utilisant des outils communautaires, des fonctions de réputation et des ressources d’information.

La source d’initialisation contient cinq projets : **Core Development — Governance Engine**, **Artisan Chain — Fair Trade Marketplace**, **Health Bridge — Telemedicine for Remote Communities**, **Academy for All — Free Web3 Education** et **Climate Sentinel Pi — Real-Time Air Quality Network**. Le chargeur synchronise ces données et renseigne des horodatages UTC valides.

L’interface prend en charge dix langues. Un audit couvrant 49 routes a permis de reconnecter au moteur i18n des dictionnaires secondaires, russes et de contenu, et de traduire les libellés de statut et de catégorie des projets. Le rapport répertorie les pages et composants qui restent partiellement ou non traduits, ainsi que les contenus backend conservés uniquement en anglais : la couverture n’est donc pas encore complète.

Les paiements Pi suivent un parcours User-to-App : authentification du Pioneer, approbation dans le wallet, puis finalisation et vérification côté serveur. `PI_API_KEY` reste côté backend et doit être fournie par un gestionnaire de secrets ; `OIDC_CLIENT_ID` est réservé à Atoms/OIDC.

Les pages Privacy et Terms sont disponibles en dix langues. Les ressources marketing comprennent une feuille de route en Markdown et en PDF ainsi qu’un pack de visuels intégrant le logo Atlasphere officiel.

# Project Module Description

- **Projets et contributions** : découverte, suivi et financement des projets.
- **Données de projets** : source d’initialisation des cinq projets Atlasphere ; le chargeur synchronise les projets et renseigne leurs horodatages.
- **Gouvernance** : propositions et votes, dont le vote quadratique.
- **Paiements Pi** : parcours User-to-App, reprise des paiements inachevés, callbacks et finalisation idempotente côté backend.
- **Authentification** : connexion Pi Network dans Pi Browser et callback `/auth/callback`.
- **Profils et communauté** : profils, commentaires, messagerie et notifications.
- **Avis des Pioneers** : notes, commentaires et statistiques sur `/feedback`.
- **Quêtes et réputation** : progression, badges, parrainage et suivi de réputation.
- **Fonctionnalités d’écosystème** : assistant IA, API d’écosystème, NFT, prédictions, carte, suivi de projets et analyses.
- **Internationalisation** : sélecteur de langue, moteur i18n et dictionnaires pour dix langues. Certaines pages et certains contenus restent à traduire ; consulter `I18N_AUDIT.md`.
- **Tests et administration** : tests de paiement sur `/payment-test` ; comptes administrateurs configurés avec `VITE_ADMIN_USERNAMES`.
- **Documentation et marketing** : guides développeur, documentation API, feuille de route et ressources téléchargeables.
- **Conformité** : pages juridiques localisées en dix langues.

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via un gestionnaire de secrets ; ne pas exposer cette clé dans le frontend ni dans le dépôt. Le flux Pi Network utilise `Pi.authenticate(...)` dans Pi Browser. `OIDC_CLIENT_ID` concerne uniquement Atoms/OIDC.

Configurer les variables frontend nécessaires, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs Pi. Plusieurs noms peuvent être séparés par des virgules.

Utiliser Mainnet pour les paiements réels et Testnet/Sandbox pour les essais ; la configuration réseau et la clé serveur doivent correspondre. La clé publique de validation se trouve dans `app/frontend/public/validation-key.txt`.

## Installer les dépendances

```bash
cd app/frontend
pnpm install
```

```bash
pip install -r requirements.txt
```

## Démarrer et vérifier

Depuis la racine du projet, démarrer les services :

```bash
bash app/start_app_v2.sh
```

Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

La source `app/backend/mock_data/projects.json` contient les cinq projets Atlasphere. Le chargeur synchronise cette source avec la table `projects` et renseigne les dates de création et de mise à jour en UTC.

Consulter `I18N_AUDIT.md` pour connaître la couverture des traductions et les pages restant à traiter. L’audit et les corrections transversales ont été validés par lint, build et vérification du rendu principal ; les contenus backend stockés en anglais et les pages signalées dans le rapport nécessitent encore une attention particulière.

Les paiements se testent sur `/payment-test` et les avis des Pioneers sur `/feedback`. Effectuer les essais Pi dans Pi Browser avec une application enregistrée et un domaine validé dans le Developer Portal.
