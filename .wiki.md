# Project Summary
Le projet **Atlasphere** est une plateforme de gouvernance décentralisée dédiée à la communauté Pi Network. Elle permet aux utilisateurs de soumettre, financer et gérer des propositions tout en intégrant des solutions innovantes pour la gestion environnementale via EcoChain AI. Atlasphere propose une application mobile multilingue (FR, EN, ES, PT, ZH, AR) qui inclut un portefeuille Eco, le suivi des indicateurs climatiques, et un marché de données. Les fonctionnalités récentes comprennent **EcoNFT**, **Abonnement Premium**, **Messagerie**, **Suivi de Projets**, ainsi que des outils avancés de gouvernance et d'IA. Parmi les ajouts récents, on trouve un système de notifications personnalisées, un tableau de bord personnalisable, et un système de récompenses pour stimuler l'engagement des utilisateurs. Les nouvelles fonctionnalités incluent également un stockage décentralisé IPFS, un système de parrainage, des partenariats avec des ONG, des éco-publicités, et un profil utilisateur enrichi.

# Project Module Description
Le projet est structuré en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données, et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission, et la gestion des propositions.
- **Assistant IA** : Propose des suggestions en temps réel.
- **Système de Quêtes** : Gère les quêtes et les récompenses.
- **Abonnements** : Gestion des abonnements.
- **Système de Commentaires** : Discussions sur les propositions.
- **Documentation API** : Détails sur les endpoints de l'API.
- **EcoWallet** : Gestion du portefeuille Pi + ECO.
- **Climate Dashboard** : Tableau de bord climatique.
- **EcoMarket** : Place de marché pour des datasets climatiques.
- **Predictions** : Alertes et analyses prédictives.
- **DAO Avancée** : Fonctionnalités de gouvernance quadratique et trésorerie communautaire.
- **Notifications Personnalisées** : Gestion des préférences de notification des utilisateurs.
- **Tableau de Bord Personnalisable** : Interface pour choisir les informations à afficher.
- **Système de Récompenses** : Encourage l'engagement des utilisateurs à travers des actions et des récompenses.
- **Stockage Décentralisé IPFS** : Gestion de fichiers avec CID et statistiques d'accès.
- **Système de Parrainage** : Mécanisme de referral avec récompenses.
- **Partenariats avec ONG** : Collaboration avec des organisations environnementales.
- **Éco-Publicités** : Publicités opt-in pour gagner des ECO tokens.
- **Profil Utilisateur Enrichi** : Informations détaillées sur l'utilisateur et ses contributions.

# File Description Inventory
- **app/backend/** : API backend, incluant la configuration et les modèles de données.
- **app/frontend/** : Interface utilisateur, incluant les composants React et les styles.
- **app/frontend/index.html** : Fichier HTML principal avec le script Pi SDK.
- **app/frontend/src/pages/** : Pages de l'application, y compris les nouvelles pages pour le stockage IPFS, le parrainage, les partenaires, les éco-publicités, et le profil utilisateur enrichi.
- **app/frontend/src/components/** : Composants réutilisables, y compris la barre de navigation et le système de notifications.
- **app/frontend/src/lib/advanced-features.ts** : Contient les interfaces et les fonctions pour les fonctionnalités avancées telles que le stockage IPFS, le parrainage, les partenaires, et les éco-publicités.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS.
- **IA** : Intégration des services d'Atomes Cloud pour l'assistance IA.
- **Pi Network** : Intégration du SDK Pi Network v2.0.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
