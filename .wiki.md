# Project Summary
Atlasphere est une super-application décentralisée sur Pi Network qui permet aux Pioneers de proposer, voter et financer des initiatives locales via gouvernance communautaire et tokens, avec un tableau de bord climat et des quêtes gamifiées pour suivre l’impact et engager la communauté autour d’actions environnementales.

# Project Module Description
- Backend (FastAPI) : API, authentification, modèles/migrations (Alembic), services dont la validation Pi et gestion des flux liés à Pi.
- Frontend (React/Vite) : pages de gouvernance (propositions, délégation, commentaires), engagement (récompenses, quêtes), portefeuille (EcoWallet) et contenus marketing.
- Validation Pi (servie en texte brut) : la clé de validation doit être accessible via `/validation-key.txt` avec un `Content-Type: text/plain` pour que Pi Network la lise correctement (sans fallback SPA renvoyant `index.html`).
- Stockage décentralisé (IPFS) : intégration pour stocker des fichiers et indexer par CID.

# File Description Inventory
- app/backend/requirements.default / app/backend/requirements.txt : dépendances backend.
- app/frontend/public/validation-key.txt : clé de validation servie en texte brut pour Pi Network.
- app/frontend/public/validation-key.txt (contenu) : hex de la clé, sans saut de ligne final.
- app/frontend/public/.well-known/test.txt : fichier de test.
- app/frontend/public/_redirects : règles de routage SPA et exceptions.
- app/frontend/public/_headers : headers pour contrôles spécifiques.
- app/backend/routers/pi_validation.py : endpoint(s) de validation Pi.
- app/frontend/src/pages/ValidationKey.tsx : page React dédiée à l’affichage/consommation de la clé.

# Technology Stack
- Backend : Python, FastAPI, SQLAlchemy, Alembic
- Frontend : React, TypeScript, Tailwind CSS, Vite
- Pi Network : SDK Pi Network (v2.0) pour paiements/validation
- IA : Atoms Cloud
- Outils : JSZip, file-saver

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
```
