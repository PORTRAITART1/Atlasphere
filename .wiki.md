# Project Summary
Atlasphere is a decentralized governance super-app for Pi Network Pioneers that enables the community to propose, vote, and fund local initiatives, while using token-driven coordination, an impact dashboard (climate-focused tracking), and gamified quests to activate participation—now including an internationalized EcoWallet experience to better communicate eco-impact progress across multiple languages.

# Project Module Description
- Frontend (React/Vite): Provides the user experience for governance (proposals, voting, comments), community engagement (quests/rewards), user profile, and the marketing content consumed by the UI; includes the EcoWallet page for eco-impact/eco-reward display with i18n-ready dynamic content.
- Backend (FastAPI): Exposes APIs for authentication, data models/migrations, and domain services around Pi validation and Pi/payment flow orchestration.
- Pi Validation (backend): Serves Pi Network validation key endpoints as raw text (no SPA behavior).
- Assets/Content: Frontend serves required static assets (marketing images, icons) and the validation key.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Frontend: React, TypeScript, Tailwind CSS, Vite, pnpm
- Pi Network: Pi Network SDK (v2.0)
- Storage/Content: Frontend public assets (marketing/branding and validation-key); referenced content via CIDs where applicable

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
pnpm run lint
```
