# Project Summary
Le projet **Atlasphere** est une super-application décentralisée construite sur Pi Network, intégrant la gouvernance décentralisée, le financement participatif et l'intelligence artificielle environnementale. Atlasphere permet aux utilisateurs de soumettre des propositions, de voter sur des projets communautaires et de financer des initiatives locales en utilisant des tokens Pi. Les Pioneers peuvent également participer à un écosystème EcoChain AI pour surveiller le climat, gagner des tokens ECO, et réduire leur empreinte carbone. La plateforme propose des quêtes gamifiées, une messagerie communautaire, et un tableau de bord climatique, le tout disponible en plusieurs langues. Récemment, des visuels marketing ont été créés pour promouvoir le projet, intégrant le logo d'Atlasphere.

# Project Module Description
Le projet est structuré en plusieurs modules fonctionnels :
- **Backend** : Gestion de l'API, de l'authentification, de la base de données, et intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la gestion des propositions et interactions communautaires.
- **Assistant IA** : Suggestions en temps réel.
- **Système de Quêtes** : Gestion des quêtes et des récompenses.
- **Abonnements** : Gestion des abonnements premium.
- **Système de Commentaires** : Discussions sur les propositions.
- **Documentation API** : Détails sur les endpoints de l'API.
- **EcoWallet** : Gestion du portefeuille Pi + ECO.
- **Climate Dashboard** : Tableau de bord climatique avec données en temps réel.
- **EcoMarket** : Place de marché pour des datasets climatiques et crédits carbone.
- **Predictions** : Alertes et analyses prédictives.
- **DAO Avancée** : Gouvernance quadratique et trésorerie communautaire.
- **Notifications Personnalisées** : Gestion des préférences de notification.
- **Tableau de Bord Personnalisable** : Interface pour sélectionner les informations à afficher.
- **Système de Récompenses** : Encourage l'engagement des utilisateurs.
- **Stockage Décentralisé IPFS** : Gestion de fichiers avec CID et statistiques.
- **Système de Parrainage** : Mécanisme de referral avec récompenses.
- **Partenariats avec ONG** : Collaboration avec des organisations environnementales.
- **Éco-Publicités** : Publicités opt-in pour gagner des ECO tokens.
- **Profil Utilisateur Enrichi** : Informations sur l'utilisateur et ses contributions.

# File Description Inventory
- **app/backend/** : API backend, incluant la configuration et les modèles de données.
- **app/frontend/** : Interface utilisateur, incluant les composants React et les styles.
- **app/frontend/index.html** : Fichier HTML principal avec le script Pi SDK.
- **app/frontend/src/pages/** : Pages de l'application, y compris celles pour le stockage IPFS, le parrainage, les partenaires, les éco-publicités, les paramètres et le profil utilisateur enrichi.
- **app/frontend/src/components/** : Composants réutilisables, y compris la barre de navigation et le système de notifications.
- **app/frontend/src/lib/pi-sdk.ts** : Gestion des paiements Pi, incluant la reprise de paiement incomplet et les récentes mises à jour pour l'alignement avec la documentation officielle de Pi SDK.
- **app/frontend/public/docs/** : Contient des documents marketing et des feuilles de route pour le lancement sur le Mainnet, ainsi que le pack marketing contenant des images et des bannières avec le logo Atlasphere.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS.
- **IA** : Intégration des services d'Atomes Cloud pour l'assistance IA.
- **Pi Network** : Intégration du SDK Pi Network v2.0.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
