# Project Summary
Atlasphere is a decentralized governance and funding platform for Pi Network Pioneers. It enables users to submit, discuss, vote on, and fund community projects while earning participation rewards and tracking ecological impact through EcoChain and EcoWallet. The application now provides localized interfaces and content across seven languages, including secondary governance, community, security, API, subscription, notification, badge, reputation, settings, and EcoNFT pages.

# Project Module Description
- **Governance and projects:** Browse, search, filter, vote on, comment on, and fund multilingual proposals.
- **Internationalization:** Supports English, Arabic, Chinese, Russian, French, Portuguese, and Spanish. English remains the fallback language, and Arabic supports RTL layouts.
- **Secondary-page localization:** Translates network settings, subscriptions, EcoNFT, community forums, badges, notification settings, API documentation, security, and reputation pages.
- **Localized dynamic content:** Uses translation keys for interface text, categories, statuses, NFT metadata, subscription features, badge labels, security content, and reputation details.
- **Community forum:** Supports localized categories, topic creation, replies, reactions, and locale-aware date formatting.
- **EcoNFT:** Provides tokenomics information, environmental data minting, NFT filtering, rarity labels, marketplace actions, and localized NFT metadata.
- **Subscriptions:** Provides Pioneer Basic, Pro, and Elite plans with trial periods, recurring Pi payments, PiRC2 details, auto-renewal controls, and localized feature lists.
- **Network settings:** Provides Testnet/Mainnet switching, feature flags, environment-variable guidance, local persistence, and a Mainnet readiness checklist.
- **Community engagement:** Includes quests, rewards, badges, reputation, profiles, messaging, referrals, delegation, notifications, and community participation.
- **Pi integration:** Supports Pi authentication, voting, contributions, payment flows, subscription simulation, and validation-key access.
- **Backend API:** FastAPI services expose authentication, projects, governance, payments, contributions, notifications, comments, and Pi validation APIs.

- `app/frontend/src/pages/Settings.tsx`: Localized network configuration, feature flags, environment guidance, and Mainnet checklist.
- `app/frontend/src/pages/Subscriptions.tsx`: Localized PiRC2 subscription plans, trials, renewals, cancellations, and feature details.
- `app/frontend/src/pages/EcoNFT.tsx`: Localized EcoNFT tokenomics, minting, marketplace, rarity, and environmental data content.
- `app/frontend/src/pages/Community.tsx`: Localized forum categories, topics, replies, reactions, and date formatting.
- `app/frontend/src/pages/Badges.tsx`: Localized badge categories, rarity labels, levels, XP, progress, and badge details.
- `app/frontend/src/pages/NotificationSettings.tsx`: Localized notification categories, channels, preferences, and bulk actions.
- `app/frontend/src/pages/ApiDocs.tsx`: Localized API documentation sections, descriptions, parameter tables, rate limits, and best practices while preserving REST identifiers.
- `app/frontend/src/pages/Security.tsx`: Localized security features, audit history, responsible disclosure, and data-handling principles.
- `app/frontend/src/pages/Reputation.tsx`: Localized reputation score, voting weight, score breakdown, earning actions, and badges.

# Technology Stack
- **Backend:** Python, FastAPI, SQLAlchemy, Alembic
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Package manager:** pnpm
- **Pi Network:** Pi Network SDK v2.0
- **Internationalization:** TypeScript dictionaries with runtime locale selection, fallback, and RTL handling
- **Data:** JSON mock data, backend API, local storage, and client-side proposal or engagement stores
- **Deployment support:** SPA redirects, custom headers, and AWS/Lambda handler

# Usage
Install backend dependencies:
```bash
cd app/backend
pip install -r requirements.txt
```

Install frontend dependencies:
```bash
cd app/frontend
pnpm install
```

Run linting and build the frontend:
```bash
pnpm run lint
pnpm run build
```

Run the backend according to the instructions in `app/backend/README.md`.
