# Project Summary

Atlasphere est une plateforme communautaire dédiée aux projets de l’écosystème Pi Network. Les Pioneers peuvent découvrir des initiatives, contribuer en Pi, participer à leur gouvernance et échanger avec la communauté.

Les fiches projet présentent budgets et jalons. Les paiements Pi sont approuvés et finalisés par le backend, avec des contrôles de sécurité et une finalisation idempotente. Les callbacks du frontend envoient désormais des requêtes POST directes de même origine vers les routes `approve`, `complete` et `cancel`, sans en-tête d’authentification bloquant ni préflight CORS.

Une tentative de paiement à 14:01 n’avait créé aucune entrée serveur, car son callback n’atteignait pas `/approve`. Le transport a été corrigé. Après publication, les paiements doivent être retestés avec une nouvelle transaction dans Pi Browser ; une transaction expirée ne peut pas être reprise.

L’interface prend en charge dix langues, avec une couverture partielle pour certains contenus. Voir `I18N_AUDIT.md`.

`PI_API_KEY` doit rester côté backend et être fournie par un gestionnaire de secrets. `OIDC_CLIENT_ID` est réservé à Atoms/OIDC.

# Project Module Description

- **Projets et jalons** : découverte des initiatives, budgets et étapes localisés.
- **Financement** : contributions via le wallet Pi, approbation et finalisation sécurisées côté serveur, gestion des reprises.
- **Abonnements et Premium** : parcours de paiement par wallet Pi.
- **Gouvernance** : propositions et votes protégés par l’identité Pi.
- **Discussions** : commentaires, mentions « J’aime » et suppression soumise aux contrôles d’accès.
- **Authentification et profils** : connexion Pi Network, échange de jeton et profil Pioneer.
- **Communauté** : messagerie, notifications, quêtes, réputation et parrainage.
- **Fonctionnalités d’écosystème** : assistant IA, API, NFT, prédictions, carte et analyses.
- **Internationalisation** : moteur i18n, dictionnaires et localisation des projets ; voir `I18N_AUDIT.md`.
- **Administration et ressources** : tests, pages juridiques, guides et documents marketing.

# Technology Stack

- **Frontend** : React, TypeScript, Vite
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy, Alembic
- **Authentification** : Pi SDK, JWT Atlasphere et vérification serveur du jeton Pi
- **Paiements** : Pi SDK côté frontend, callbacks directs de même origine et intégration Pi Platform côté serveur
- **Client HTTP** : HTTPX
- **Internationalisation** : moteur i18n et dictionnaires multilingues
- **Dépendances** : pnpm/npm et pip
- **Secrets** : gestionnaire de secrets pour `PI_API_KEY`

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via un gestionnaire de secrets ; ne pas l’exposer dans le frontend ni dans le dépôt. `OIDC_CLIENT_ID` concerne uniquement Atoms/OIDC.

Configurer les variables frontend requises, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs. Utiliser Mainnet pour les paiements réels et Testnet/Sandbox pour les essais.

## Installer les dépendances

```bash
cd app/frontend
pnpm install
```

```bash
pip install -r requirements.txt
```

## Démarrer et vérifier

Depuis la racine du projet :

```bash
bash app/start_app_v2.sh
```

Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Le backend compile également ; le lint et le build frontend passent, et le rendu reste stable.

Pour tester les paiements après publication, lancer une transaction entièrement nouvelle dans Pi Browser. Vérifier que le wallet atteint l’écran de confirmation et que la complétion serveur est confirmée avant d’afficher le succès. Ne pas réutiliser une tentative expirée. Tester aussi les annulations, erreurs et reprises.

Pour valider l’authentification, tester l’échange du jeton Pi, les votes et les actions de commentaires. Une réponse `401` à une vérification avec un jeton de test invalide indique que l’endpoint est accessible et rejette ce jeton comme prévu.

Pour vérifier les traductions, changer la langue et consulter l’accueil, la liste et les fiches de projet. Voir `I18N_AUDIT.md` pour les traductions incomplètes.
