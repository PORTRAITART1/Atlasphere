# Project Summary

Atlasphere est une plateforme communautaire dédiée aux projets de l’écosystème Pi Network. Les Pioneers peuvent découvrir des initiatives localisées, les financer en Pi, participer à leur gouvernance et échanger avec la communauté.

Chaque projet présente un budget et trois jalons avec leur statut. Les votes et les discussions sont protégés par l’identité Pi : le JWT Atlasphere est prioritaire, avec vérification directe du jeton Pi en repli pour les routes concernées.

Les paiements passent par le wallet Pi et sont finalisés côté serveur. Pour réduire le risque d’expiration du wallet, la lecture du paiement et la vérification du jeton sont parallélisées, l’approbation est envoyée avant les écritures locales non indispensables et les appels à Pi ont des délais d’attente réduits. Le succès reste conditionné à la finalisation effective du paiement.

L’interface prend en charge dix langues, avec une couverture encore partielle pour certains contenus. Consulter `I18N_AUDIT.md`.

`PI_API_KEY` doit rester côté backend et être fournie par un gestionnaire de secrets. `OIDC_CLIENT_ID` est réservé à Atoms/OIDC.

# Project Module Description

- **Projets et jalons** : découverte des initiatives, budgets et étapes localisés.
- **Financement** : contributions par wallet Pi, approbation et finalisation serveur, gestion des erreurs, annulations et paiements incomplets.
- **Abonnements et Premium** : parcours de paiement par wallet.
- **Gouvernance** : propositions et votes protégés par l’identité Pi.
- **Discussions** : commentaires, mentions « J’aime » et suppression soumise aux contrôles d’accès.
- **Authentification et profils** : connexion Pi Network, échange de jeton, session et profil Pioneer.
- **Communauté** : messagerie, notifications, quêtes, réputation et parrainage.
- **Fonctionnalités d’écosystème** : assistant IA, API, NFT, prédictions, carte et analyses.
- **Internationalisation** : moteur i18n, dictionnaires et localisation des projets ; consulter `I18N_AUDIT.md`.
- **Administration et ressources** : tests, pages juridiques, guides et documents marketing.

# Technology Stack

- **Frontend** : React, TypeScript, Vite
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy, Alembic
- **Authentification** : Pi SDK, JWT Atlasphere et vérification serveur du jeton Pi
- **Paiements** : Pi SDK côté frontend et Pi Platform côté serveur
- **Client HTTP** : HTTPX
- **Internationalisation** : moteur i18n et dictionnaires multilingues
- **Dépendances** : pnpm/npm et pip
- **Secrets** : gestionnaire de secrets pour `PI_API_KEY`

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via un gestionnaire de secrets ; ne pas l’exposer dans le frontend ni dans le dépôt. `OIDC_CLIENT_ID` concerne uniquement Atoms/OIDC.

Configurer les variables frontend requises, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs. Utiliser Mainnet pour les paiements réels et Testnet/Sandbox pour les essais.

## Installer les dépendances

```bash
cd app/frontend
pnpm install
```

```bash
pip install -r requirements.txt
```

## Démarrer et vérifier

Depuis la racine du projet :

```bash
bash app/start_app_v2.sh
```

Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Après modification du backend, publier le déploiement avant de retester un paiement dans Pi Browser. Utiliser un nouveau paiement et vérifier l’approbation du wallet ainsi que la finalisation côté serveur. Tester aussi les annulations, erreurs et paiements incomplets ; le succès ne doit être affiché qu’après finalisation.

Pour valider l’authentification, tester l’échange du jeton Pi, les votes et les actions de commentaires. Pour vérifier les traductions, changer la langue et consulter l’accueil, la liste et les fiches de projet. Consulter `I18N_AUDIT.md` pour les traductions incomplètes.
