# Project Summary
Le projet **PoliGov** est une plateforme de gouvernance décentralisée qui permet aux utilisateurs de soumettre des propositions pour financement. En intégrant des fonctionnalités avancées d'assistance via l'IA, PoliGov facilite la rédaction et l'amélioration des propositions grâce à Atoms Cloud, favorisant ainsi la collaboration et l'innovation au sein de la communauté Pi Network. L'application respecte les normes de Pi Network, PiRC2, SDK et smart contracts, tout en offrant une expérience utilisateur améliorée avec des animations fluides et des outils de génération de contenu. PoliGov prend en charge six langues (FR, EN, ES, PT, ZH, AR) et inclut des fonctionnalités telles qu'un système de commentaires pour encourager l'interaction des utilisateurs.

# Project Module Description
Le projet est divisé en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données, et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission, et la gestion des propositions, incluant des fonctionnalités de génération d'images et de texte, ainsi que des animations.
- **Assistant IA** : Fournit des suggestions en temps réel pour améliorer les propositions.
- **Système de Quêtes** : Gère les quêtes et les récompenses pour les utilisateurs, y compris le suivi des progrès et la réclamation des récompenses.
- **Pages Légales** : Inclut la Politique de Confidentialité et les Conditions d'Utilisation, disponibles en six langues.
- **Système de Commentaires** : Permet aux utilisateurs de discuter sur les propositions, de répondre aux commentaires et de liker les contributions.

# File Description Inventory
- **app/backend/** : Fichiers relatifs à l'API backend, y compris la configuration de la base de données et les modèles de données.
- **app/frontend/** : Fichiers de l'interface utilisateur, y compris les composants React et les styles.
- **app/frontend/src/lib/pi-sdk.ts** : Intégration du SDK Pi Network v2.0, gérant l'authentification et les paiements.
- **app/frontend/src/lib/api.ts** : Service API pour connecter le frontend au backend réel.
- **app/frontend/src/lib/i18n.ts** : Gestion de l'internationalisation pour 6 langues, y compris le nouvel ajout de l'arabe.
- **app/frontend/src/pages/Quests.tsx** : Page dédiée à la gestion des quêtes et récompenses.
- **app/frontend/src/pages/Index.tsx** : Page d'accueil mise à jour pour refléter le nouveau message de gouvernance "Gouvernance Communautaire sous Pi Network".
- **app/frontend/src/pages/Privacy.tsx** : Page pour la Politique de Confidentialité, supportant 6 langues.
- **app/frontend/src/pages/Terms.tsx** : Page pour les Conditions d'Utilisation, supportant 6 langues.
- **app/frontend/src/components/Navbar.tsx** : Composant de navigation mis à jour pour inclure le sélecteur de langue et les nouvelles routes.
- **app/frontend/src/components/LanguageSelector.tsx** : Composant pour sélectionner la langue de l'interface utilisateur.
- **app/frontend/src/components/PiPaymentButton.tsx** : Bouton pour effectuer des paiements en Pi.
- **app/frontend/src/components/AIAssistant.tsx** : Composant pour l'assistant IA.
- **app/frontend/src/components/Footer.tsx** : Composant de pied de page mis à jour.
- **app/frontend/src/components/Comments.tsx** : Nouveau composant pour gérer les commentaires sur les propositions.
- **app/frontend/.env** : Fichier d'environnement pour configurer les titres et descriptions de l'application.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, framer-motion pour les animations.
- **IA** : Intégration d'Atomes Cloud pour l'assistance IA, incluant la génération de texte et d'images.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
