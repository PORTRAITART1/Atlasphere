# Project Summary

Atlasphere est une plateforme communautaire dédiée aux projets de l’écosystème Pi Network. Elle permet aux Pioneers de découvrir des initiatives, de les financer en Pi, de participer à leur gouvernance et d’échanger avec la communauté.

Les projets présentent leurs budgets et leurs jalons. L’identité Pi soutient les votes et les discussions. Les paiements sont initiés depuis le frontend, puis approuvés et finalisés côté serveur avec le client backend officiel Atoms et Pi Platform. `PI_API_KEY` doit rester côté backend et être fournie par un gestionnaire de secrets. `OIDC_CLIENT_ID` est réservé à Atoms/OIDC.

L’interface propose dix langues, avec une couverture partielle de certains contenus. Consulter `I18N_AUDIT.md` pour connaître les lacunes.

# Project Module Description

- **Projets et jalons** : découverte des initiatives, budgets et étapes localisés.
- **Financement** : contributions en Pi, approbation et finalisation côté serveur, gestion des reprises.
- **Abonnements et Premium** : parcours de paiement par wallet Pi.
- **Gouvernance** : propositions et votes liés à l’identité Pi.
- **Discussions** : commentaires, mentions « J’aime » et suppression soumise aux contrôles d’accès.
- **Authentification et profils** : connexion Pi Network, échange de jeton et profil Pioneer.
- **Communauté** : messagerie, notifications, quêtes, réputation et parrainage.
- **Fonctionnalités d’écosystème** : assistant IA, API, NFT, prédictions, carte et analyses.
- **Internationalisation** : moteur i18n, dictionnaires et localisation des projets ; consulter `I18N_AUDIT.md`.
- **Administration et ressources** : pages juridiques, guides, tests et documents marketing.

# Technology Stack

- **Frontend** : React, TypeScript et Vite.
- **Backend** : Python, FastAPI et Pydantic.
- **Base de données** : SQLAlchemy et Alembic.
- **Authentification** : Pi SDK, JWT Atlasphere et vérification serveur du jeton Pi.
- **Paiements** : Pi SDK côté frontend, client backend officiel Atoms et Pi Platform côté serveur.
- **Client HTTP** : HTTPX.
- **Internationalisation** : moteur i18n et dictionnaires multilingues.
- **Gestion des dépendances** : pnpm/npm et pip.
- **Secrets** : gestionnaire de secrets pour `PI_API_KEY`.

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via un gestionnaire de secrets ; ne pas l’exposer dans le frontend ni dans le dépôt. `OIDC_CLIENT_ID` concerne Atoms/OIDC.

Configurer les variables frontend requises, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs. Utiliser Mainnet pour les paiements réels et Testnet/Sandbox pour les essais.

## Installation des dépendances

```bash
cd app/frontend
pnpm install
```

```bash
pip install -r requirements.txt
```

## Démarrage et vérification

Depuis la racine du projet, démarrer le frontend et le backend :

```bash
bash app/start_app_v2.sh
```

Lorsque la base de données est disponible, appliquer les migrations :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Pour tester un paiement, créer une nouvelle transaction dans Pi Browser et vérifier que la finalisation côté serveur est confirmée avant d’afficher le succès. Tester également les annulations, erreurs et reprises.

Pour valider l’authentification, tester l’échange du jeton Pi, les votes et les actions de commentaires. Pour examiner les traductions, changer la langue et consulter l’accueil, la liste et les fiches de projet ; voir `I18N_AUDIT.md`.
