# Project Summary

Atlasphere est une plateforme communautaire consacrée à la découverte, au financement et à la gouvernance de projets liés à Pi Network. Les membres peuvent suivre des projets, contribuer en Pi, voter, participer à des quêtes et consulter leur activité. La plateforme inclut aussi des outils de réputation, de notification et d’assistance IA.

Les paiements Pi reposent sur le SDK v2.0 : authentification du Pioneer, approbation et signature dans le wallet, puis finalisation et vérification côté serveur. Le réseau Mainnet ou Testnet/Sandbox dépend de l’environnement ; la clé API Pi reste côté backend.

La clé publique de validation Pi actuellement affichée sur `/validation-key.txt` est `52896834080544f82daa4685523aae376b5d41c776a294c25cc8e92fca007aa90f99747022ba816f3030b530a6d65825fc78f0cbca82da14791b52b746f4ba03`.

La page `/feedback` permet aux Pioneers de noter l’application, de publier un commentaire et de consulter les avis et statistiques associés à un paiement vérifié.

# Project Module Description

- **Projets et contributions** : découverte, suivi et financement de projets. Les contributions sont créditées après confirmation du paiement.
- **Gouvernance** : propositions, votes et vote quadratique.
- **Paiements Pi** : parcours User-to-App, reprise des paiements inachevés, callbacks et registre idempotent.
- **Validation Pi** : publication de la clé de validation via `/validation-key.txt`.
- **Profils et communauté** : authentification Pi, profils, commentaires, messagerie et notifications.
- **Avis des Pioneers** : notes, commentaires et statistiques sur `/feedback`, accessible depuis le menu « Plus » et le pied de page.
- **Quêtes et réputation** : progression, badges, parrainage et suivi de réputation.
- **Fonctionnalités d’écosystème** : assistant IA, API d’écosystème, NFT, prédictions, carte, suivi de projets et analyses.
- **Tests de paiement** : `/payment-test` pour tester les paiements et suivre les testeurs.
- **Administration et configuration** : `/settings` et `/admin` dépendent de la liste de noms Pi configurée dans `VITE_ADMIN_USERNAMES`.
- **Documentation et conformité** : guides développeur, documentation API, ressources marketing et pages légales localisées.

# Technology Stack

- **Frontend** : React, TypeScript, Vite
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy, Alembic
- **Paiements** : Pi SDK v2.0 côté frontend et API Pi Platform côté serveur
- **Client HTTP** : HTTPX
- **Internationalisation** : traductions JSON et modules i18n
- **Gestion des dépendances** : pnpm/npm et pip

# Usage

## Configuration

Configurer `PI_API_KEY` dans l’environnement serveur ; ne pas exposer cette clé dans le frontend.

Configurer les variables frontend nécessaires, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs Pi. La liste accepte plusieurs noms séparés par des virgules.

Choisir le réseau de paiement adapté à l’environnement et au wallet : Mainnet pour les paiements réels, Testnet/Sandbox pour les essais. La clé serveur et le réseau doivent correspondre. Republier le frontend après toute modification de sa configuration.

La clé de validation publique est consultable via `/validation-key.txt`.

## Installer les dépendances

Installer les dépendances frontend :

```bash
cd app/frontend
pnpm install
```

Installer les dépendances Python depuis le backend, avec le fichier adapté à l’environnement :

```bash
cd app/backend
pip install -r requirements.txt
```

## Démarrer et vérifier

Depuis la racine du projet, démarrer l’application :

```bash
bash app/start_app_v2.sh
```

Pour appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Les parcours de paiement se testent sur `/payment-test` et les avis des Pioneers sur `/feedback`. Effectuer les essais Pi dans Pi Browser avec une application enregistrée et un domaine validé dans le Developer Portal.
