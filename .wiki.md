# Project Summary

Atlasphere est une plateforme communautaire dédiée à la découverte, au financement et à la gouvernance de projets liés à Pi Network. Les membres peuvent suivre des projets, contribuer en Pi, voter sur des propositions, participer à des quêtes et suivre leur activité. La plateforme propose également des outils d’écosystème, de réputation, de notifications et d’assistance IA.

Les paiements Pi suivent le flux Pi SDK v2.0 : authentification du Pioneer, création et approbation du paiement, signature dans le wallet, puis complétion et vérification côté serveur. Le réseau Mainnet ou Testnet/Sandbox est sélectionné explicitement ; la clé API Pi reste côté backend.

La page `/feedback` permet aux Pioneers de noter l’application, de publier un commentaire et de consulter les statistiques et les avis associés à un paiement vérifié.

# Project Module Description

- **Projets et contributions** : découverte, suivi et financement des projets. Les contributions sont créditées après confirmation du paiement.
- **Gouvernance** : propositions, votes et vote quadratique.
- **Paiements Pi** : parcours User-to-App, reprise des paiements inachevés, callbacks et registre idempotent pour éviter les crédits en double.
- **Profils et communauté** : authentification Pi, profils, commentaires, messagerie, notifications et paramètres de notification.
- **Avis des Pioneers** : notes, commentaires, statistiques et distinction des avis associés à un paiement vérifié sur `/feedback`. La page est accessible depuis le menu « Plus » et le pied de page.
- **Quêtes et réputation** : quêtes, progression, badges, parrainage et suivi de réputation.
- **Fonctionnalités d’écosystème** : assistant IA, API d’écosystème, NFT, prédictions, carte, suivi de projets et analyses.
- **Test des paiements** : `/payment-test` permet de tester les paiements et de suivre les testeurs.
- **Administration et configuration** : `/settings` et `/admin` sont soumis à la liste de noms Pi configurée dans `VITE_ADMIN_USERNAMES`.
- **Documentation et conformité** : guides développeur, documentation API, ressources marketing et pages localisées de confidentialité et de conditions d’utilisation.

# Technology Stack

- **Frontend** : React, TypeScript, Vite
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy et Alembic
- **Paiements** : Pi SDK v2.0 côté frontend et API Pi Platform côté serveur
- **Client HTTP** : HTTPX
- **Internationalisation** : traductions JSON et modules i18n
- **Gestion des dépendances** : pnpm/npm et pip

# Usage

## Configuration

Configurer `PI_API_KEY` dans l’environnement serveur. Ne jamais exposer cette clé dans le frontend.

Configurer les variables frontend nécessaires, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs Pi. Cette liste accepte plusieurs noms séparés par des virgules.

Choisir explicitement le réseau de paiement correspondant à l’environnement et au wallet : Mainnet pour les paiements réels, Testnet/Sandbox pour les essais. La clé serveur et le réseau doivent correspondre. Republier le frontend après toute modification de sa configuration.

## Installer les dépendances

```bash
cd app/frontend
pnpm install
```

Installer les dépendances Python depuis le répertoire backend avec le fichier adapté à l’environnement :

```bash
cd app/backend
pip install -r requirements.txt
```

## Lancer et vérifier

Démarrer le backend avec la commande de lancement définie par la configuration du projet. Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Les principaux parcours de paiement se trouvent sur `/payment-test`. La page d’avis des Pioneers est accessible sur `/feedback`. Effectuer les essais Pi dans Pi Browser avec une application enregistrée et un domaine validé dans le Developer Portal. Vérifier que le compte, le wallet, le mode réseau et la clé serveur ciblent le même réseau.
