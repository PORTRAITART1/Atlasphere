# Project Summary
Le projet PiDAO est une plateforme de gouvernance décentralisée construite sur le réseau Pi, permettant aux utilisateurs de soumettre des propositions de projets, de voter sur des initiatives communautaires et de financer des projets approuvés avec la cryptomonnaie Pi. Il vise à renforcer l'engagement des Pionniers dans la construction de l'écosystème Pi à travers des décisions participatives et un système de réputation.

# Project Module Description
- **Frontend**: Interface utilisateur de la plateforme, développée avec React, incluant des composants pour la navigation, les propositions de projets, le tableau de bord personnel, et les fonctionnalités de financement participatif.
- **Backend**: Simule l'authentification et les transactions via un SDK Pi fictif, gérant les données et les interactions utilisateur.

# File Description Inventory
- **src/App.tsx**: Point d'entrée principal de l'application React.
- **src/components/**: Contient des composants UI réutilisables tels que Navbar, Footer, et ProposalCard.
- **src/pages/**: Comprend différentes pages de l'application, telles que Index, Proposals, ProposalDetail, CreateProposal, Funding, et Dashboard.
- **src/lib/**: Contient des fonctions utilitaires et des intégrations API, y compris la simulation du SDK Pi.
- **src/hooks/**: Hooks React personnalisés pour la gestion de l'état et des effets.
- **src/styles/**: Styles globaux et spécifiques aux composants.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **State Management**: Hooks personnalisés et état local
- **Routing**: React Router
- **Payment Handling**: SDK fictif du réseau Pi
- **Internationalization**: Implémentation personnalisée d'i18n
- **Build Tools**: Vite, ESLint, PostCSS

# Usage
1. **Installer les Dépendances**:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. **Construire le Projet**:
   ```bash
   pnpm run build
   ```
3. **Exécuter le Projet**:
   ```bash
   pnpm run start
   ```
