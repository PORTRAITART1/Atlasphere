# Project Summary

Atlasphere est une plateforme communautaire de découverte, de financement et de gouvernance de projets liés à Pi Network. Les membres peuvent suivre des projets, contribuer en Pi, voter, accomplir des quêtes, échanger et consulter leur activité. La plateforme comprend aussi des outils de réputation, des notifications et une assistance IA.

Les paiements Pi suivent un parcours User-to-App : authentification du Pioneer, approbation dans le wallet, puis finalisation et vérification côté serveur. Le réseau Mainnet ou Testnet/Sandbox dépend de l’environnement. L’authentification Pi Network utilise `Pi.authenticate(...)` dans Pi Browser, puis le backend vérifie le jeton Pi.

La clé Pi App API est injectée dans le backend sous `PI_API_KEY` via le gestionnaire de secrets. Elle ne doit pas être exposée dans le frontend, le dépôt ou le chat. `OIDC_CLIENT_ID` concerne l’authentification Atoms/OIDC.

Pour Pi Sign-In dans Pi Develop, l’URI de redirection à enregistrer est `https://atlasphere.pub.atoms.world/auth/callback`. La clé publique de validation Pi est publiée à `/validation-key.txt`. Les pages juridiques sont accessibles via `/terms.html` et `/privacy.html`.

# Project Module Description

- **Projets et contributions** : découverte, suivi et financement de projets. Les contributions sont créditées après confirmation du paiement.
- **Gouvernance** : propositions et votes, y compris le vote quadratique.
- **Paiements Pi** : parcours User-to-App, reprise des paiements inachevés, callbacks et registre idempotent. La configuration et la finalisation sont gérées côté backend.
- **Authentification** : authentification Pi Network dans Pi Browser et callback `/auth/callback`.
- **Profils et communauté** : profils, commentaires, messagerie et notifications.
- **Avis des Pioneers** : notes, commentaires et statistiques sur `/feedback`.
- **Quêtes et réputation** : progression, badges, parrainage et suivi de réputation.
- **Fonctionnalités d’écosystème** : assistant IA, API d’écosystème, NFT, prédictions, carte, suivi de projets et analyses.
- **Tests de paiement** : `/payment-test` pour tester les paiements et suivre les testeurs.
- **Administration** : `/settings` et `/admin` dépendent des noms Pi définis dans `VITE_ADMIN_USERNAMES`.
- **Documentation et conformité** : guides développeur, documentation API, ressources marketing et pages juridiques HTML localisées.

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via le gestionnaire de secrets. Ne pas exposer cette clé dans le frontend, le dépôt ou les échanges de chat.

Dans Pi Develop, pour Pi Sign-In, enregistrer l’URI de redirection suivante :

```text
https://atlasphere.pub.atoms.world/auth/callback
```

Le flux Pi Network utilise `Pi.authenticate(...)` dans Pi Browser et ne nécessite pas d’Auth Client ID Pi. `OIDC_CLIENT_ID` est réservé au flux Atoms/OIDC.

Dans les paramètres de l’application Pi, conservez le sous-domaine `atlasphere` s’il est disponible, sélectionnez **backend** comme type de prise en charge des métadonnées, puis soumettez le formulaire. L’option plein écran est facultative.

Configurer les variables frontend nécessaires, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs Pi. Plusieurs noms peuvent être séparés par des virgules.

Choisir le réseau correspondant à l’environnement et au wallet : Mainnet pour les paiements réels, Testnet/Sandbox pour les essais. La clé serveur et le réseau doivent correspondre.

La clé publique de validation est fournie par `app/frontend/public/validation-key.txt`. Les pages juridiques sont `app/frontend/public/terms*.html` et `app/frontend/public/privacy*.html`.

## Installer les dépendances

Dépendances frontend :

```bash
cd app/frontend
pnpm install
```

Dépendances Python :

```bash
cd app/backend
pip install -r requirements.txt
```

## Démarrer, migrer et vérifier

Depuis la racine du projet, lancer l’application :

```bash
bash app/start_app_v2.sh
```

Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Les paiements se testent sur `/payment-test` et les avis des Pioneers sur `/feedback`. Effectuer les essais Pi dans Pi Browser avec une application enregistrée et un domaine validé dans le Developer Portal.
