# Project Summary
Atlasphere est une super-application décentralisée sur Pi Network qui permet aux Pioneers de proposer, voter et financer des initiatives locales via gouvernance communautaire et tokens, avec un tableau de bord orienté climat et des quêtes gamifiées pour suivre l’impact et engager la communauté.

# Project Module Description
- Backend (FastAPI) : expose des APIs, gère l’authentification, les modèles et migrations DB (Alembic), et fournit des services dont la validation Pi et le pilotage des flux liés à Pi.
- Frontend (React/Vite) : pages de gouvernance (propositions, délégation, commentaires), parcours d’engagement (récompenses, quêtes), portefeuille (EcoWallet) et contenus marketing.
- Validation Pi : ressource texte brut servie en texte brut pour la validation, sans comportement SPA.
- Stockage décentralisé (IPFS) : intégration pour stocker des fichiers et référencer via CID.

# File Description Inventory
- app/backend/requirements.default / app/backend/requirements.txt : dépendances backend.
- app/frontend/public/validation-key.txt : clé de validation servie en texte brut pour Pi Network.
- app/frontend/public/validation-key.txt (contenu) : hex de la clé, sans saut de ligne final.
- app/frontend/public/.well-known/test.txt : fichier de test.
- app/frontend/public/_redirects : règles de routage SPA et exceptions.
- app/frontend/public/_headers : headers pour contrôles spécifiques.
- app/backend/routers/pi_validation.py : endpoint(s) de validation Pi.
- app/frontend/src/pages/ValidationKey.tsx : page React dédiée à l’affichage/consommation de la clé.
- app/frontend/src/pages/UserProfile.tsx : page profil utilisateur, affichage des stats, bouton de déconnexion et upload d’avatar.
- app/frontend/src/lib/i18n.ts : définitions de clés de traduction, incluant désormais celles du profil.

# Technology Stack
- Backend : Python, FastAPI, SQLAlchemy, Alembic
- Frontend : React, TypeScript, Tailwind CSS, Vite
- Pi Network : SDK Pi Network (v2.0) pour paiements/validation
- IA : Atoms Cloud
- Outils : JSZip, file-saver

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
```
