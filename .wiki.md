# Project Summary
The PiMarket project is a decentralized marketplace built on the Pi Network, enabling users to buy, sell, and trade products and services using Pi cryptocurrency. It aims to empower Pioneers by providing them with a secure and user-friendly platform for commerce, leveraging smart contracts for subscriptions and transactions.

# Project Module Description
- **Frontend**: The user interface of the marketplace, built with React, featuring components for navigation, product listings, user profiles, and shopping cart functionalities.
- **Backend**: Utilizes the Pi Network SDK to handle authentication, payments, and data management.

# File Description Inventory
- **src/App.tsx**: Main entry point for the React application.
- **src/components/**: Contains reusable UI components such as Navbar, Footer, and ProductCard.
- **src/pages/**: Contains different pages of the application, such as Index, Marketplace, ProductDetail, Cart, Subscriptions, Profile, and Seller.
- **src/lib/**: Contains utility functions and API integrations, including the Pi SDK simulation.
- **src/hooks/**: Custom React hooks for managing state and effects.
- **src/styles/**: Global and component-specific styles.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **State Management**: Custom hooks and local state
- **Routing**: React Router
- **Payment Handling**: Pi Network SDK
- **Internationalization**: Custom i18n implementation
- **Build Tools**: Vite, ESLint, PostCSS

# Usage
1. **Install Dependencies**:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. **Build the Project**:
   ```bash
   pnpm run build
   ```
3. **Run the Project**:
   ```bash
   pnpm run start
   ```
