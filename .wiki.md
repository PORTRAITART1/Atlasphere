# Project Summary
Atlasphere est une super-application décentralisée sur Pi Network qui permet aux Pioneers de proposer, voter et financer des initiatives locales via la gouvernance communautaire et des tokens, tout en s’appuyant sur des données climatiques pour suivre l’impact. La plateforme propose un tableau de bord climat, des quêtes gamifiées et une boucle d’incitation (récompenses, EcoWallet, parrainage) pour engager la communauté autour d’actions environnementales.

# Project Module Description
- **Backend (FastAPI)** : API, authentification, modèles et migrations (Alembic), services (incluant la validation Pi) et gestion des paiements/flux liés à Pi.
- **Frontend (React/Vite)** : Interface pour la gouvernance (propositions, détails, délégation, commentaires), l’engagement (récompenses, quêtes), l’écosystème (EcoWallet, EcoAds, partenaires, referral), et l’interface marketing (téléchargement).
- **Validation Pi (accès depuis le frontend/deployment)** : mécanisme de vérification du domaine via une ressource “validation-key” exposée côté contenu, en plus de la possibilité de validation via l’API backend.
- **EcoWallet & i18n** : gestion portefeuille Pi/ECO et internationalisation de l’interface.
- **Stockage décentralisé (IPFS)** : intégration pour le stockage de fichiers et leur indexation (CID).

# File Description Inventory
- **app/backend/requirements.default** / **app/backend/requirements.txt** : ajustement des dépendances backend.
- **app/frontend/public/validation-key.txt** : clé de validation de domaine exposée comme ressource statique.
- **app/frontend/public/.well-known/test.txt** : fichier de test ajouté dans le répertoire well-known.
- **app/frontend/public/_redirects** : règles de routage SPA (incluant des exceptions pour servir correctement certains chemins).
- **app/frontend/public/_headers** : headers pour contrôler la réponse de la ressource de validation.
- **app/backend/routers/pi_validation.py** : endpoint backend permettant la validation Pi via l’API (chemin `/api/v1/pi/...`).

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, Vite, JSZip, file-saver.
- **IA** : intégration d’un service Atoms Cloud pour l’assistance IA.
- **Pi Network** : SDK Pi Network (v2.0) pour paiements/validation.

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
```
