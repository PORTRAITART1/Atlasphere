# Project Summary
Atlasphere is a decentralized governance and community funding platform for Pi Network Pioneers. Users can discover, discuss, vote on, and fund projects while tracking participation, reputation, rewards, and ecological impact through EcoChain and EcoWallet. The platform supports seven localized languages, Pi-based interactions, subscription plans, EcoNFT features, community tools, and downloadable marketing assets.

# Project Module Description
- **Governance and funding:** Browse, filter, discuss, vote on, and fund community proposals.
- **Internationalization:** Supports English, Arabic, Chinese, Russian, French, Portuguese, and Spanish, with English fallback and Arabic RTL support.
- **Community engagement:** Provides forums, profiles, messaging, referrals, delegation, quests, badges, reputation, notifications, and rewards.
- **EcoChain and EcoNFT:** Displays environmental data, ecological impact, tokenomics, NFT metadata, rarity, minting, and marketplace features.
- **Subscriptions:** Provides Pioneer Basic, Pro, and Elite plans with trials, recurring Pi payments, renewal controls, and localized features.
- **Pi integration:** Supports authentication, voting, contributions, payments, subscription flows, and validation-key access.
- **Backend API:** FastAPI services cover authentication, projects, governance, payments, contributions, comments, notifications, and Pi validation.
- **Administrator access:** Restricts network settings and administrator routes to configured Pi usernames. Non-administrators receive localized access-denied or sign-in guidance.
- **Marketing downloads:** Provides ten branded store assets in square introductory and vertical preview formats, with individual downloads and ZIP inclusion.

# File Description Inventory
- `app/frontend/src/lib/admin.ts`: Reads `VITE_ADMIN_USERNAMES`, normalizes administrator usernames, and checks the authenticated Pi user.
- `app/frontend/src/components/AdminGuard.tsx`: Protects administrator-only pages and displays localized authentication or permission messages.
- `app/frontend/src/App.tsx`: Applies administrator protection to restricted routes and composes application providers.
- `app/frontend/src/components/Navbar.tsx`: Hides restricted navigation entries from non-administrators.
- `app/frontend/src/components/Footer.tsx`: Hides restricted footer links from non-administrators.
- `app/frontend/src/pages/MarketingDownload.tsx`: Displays and packages the INTRO and PREVIEW marketing asset collections.
- `app/frontend/scripts/build_store_assets.py`: Downloads source backgrounds, overlays the official Atlasphere logo and wordmark, creates exact-size PNGs, and keeps files below the size limit.
- `app/frontend/public/marketing-pack/store-assets/`: Contains five 400×400 introductory visuals and five 750×1500 preview visuals.
- `app/frontend/src/lib/locales/pages-*.ts`: Adds localized administrator access, sign-in, and permission messages in all supported languages.
- `app/frontend/image_manifest.json`: Tracks frontend image assets.
- `app/frontend/src/lib/i18n.ts`: Registers locales, merges dictionaries, handles fallback behavior, and manages RTL support.
- `app/frontend/src/lib/api.ts`: Retrieves and localizes project content, categories, statuses, and milestones.
- `app/frontend/src/lib/store.ts`: Defines proposal models, project records, milestones, filters, statistics, votes, and contributions.
- `app/frontend/public/validation-key.txt`: Stores the raw Pi Network validation key.
- `app/frontend/public/_redirects`: Defines SPA routing and deployment exceptions.
- `app/frontend/public/_headers`: Defines deployment header rules.

# Technology Stack
- **Backend:** Python, FastAPI, SQLAlchemy, Alembic
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Package manager:** pnpm
- **Pi Network:** Pi Network SDK v2.0
- **Internationalization:** TypeScript dictionaries with runtime locale selection, fallback, and RTL handling
- **Access control:** Build-time administrator configuration through `VITE_ADMIN_USERNAMES`
- **Data:** JSON mock data, backend API, local storage, and client-side stores
- **Image processing:** Python, Pillow, and generated PNG marketing assets
- **Deployment:** SPA redirects, custom headers, and AWS/Lambda handler

# Usage
Install backend dependencies:
```bash
cd app/backend
pip install -r requirements.txt
```

Install frontend dependencies:
```bash
cd app/frontend
pnpm install
```

Configure administrator usernames at build time:
```bash
VITE_ADMIN_USERNAMES="admin_one,admin_two" pnpm run build
```

If not configured, the frontend uses its built-in administrator fallback usernames.

Generate or refresh marketing store assets:
```bash
cd app/frontend
python3 scripts/build_store_assets.py
```

Run linting and build the frontend:
```bash
pnpm run lint
pnpm run build
```

Run the backend according to `app/backend/README.md`.
