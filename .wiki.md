# Project Summary
Le projet **Atlasphere** est une plateforme de gouvernance décentralisée qui permet aux utilisateurs de soumettre et de financer des propositions au sein de la communauté Pi Network. En intégrant les fonctionnalités d'EcoChain AI, Atlasphere se transforme en une application mobile complète offrant des outils avancés de gestion environnementale. Les utilisateurs peuvent gérer un portefeuille Eco, suivre des indicateurs climatiques, et accéder à un marché de données environnementales. L'application est multilingue (FR, EN, ES, PT, ZH, AR) et favorise la collaboration communautaire via des systèmes de commentaires et d'intégration sociale. Les récentes mises à jour ont renforcé la **Documentation API**, la **Sécurité & Transparence**, et amélioré les performances, tout en assurant la conformité avec les standards de développement du Pi Network. De plus, de nouvelles fonctionnalités telles que **EcoNFT** et **Abonnement Premium** ont été ajoutées pour enrichir l'expérience utilisateur.

# Project Module Description
Le projet est structuré en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données, et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission, et la gestion des propositions, incluant des animations et des composants réutilisables.
- **Assistant IA** : Propose des suggestions en temps réel pour améliorer les propositions.
- **Système de Quêtes** : Gère les quêtes et les récompenses pour les utilisateurs.
- **Abonnements** : Gestion des abonnements avec différents plans tarifaires.
- **Pages Légales** : Politique de Confidentialité et Conditions d'Utilisation.
- **Système de Commentaires** : Discussions sur les propositions.
- **Documentation API** : Détails sur les endpoints de l'API et meilleures pratiques.
- **Sécurité & Transparence** : Informations sur les mesures de sécurité.
- **Délégation de Votes** : Permet aux utilisateurs de déléguer leur poids de vote.
- **EcoWallet** : Gestion du portefeuille Pi + ECO avec des fonctionnalités de récompenses.
- **Climate Dashboard** : Tableau de bord climatique avec des données environnementales.
- **EcoMarket** : Place de marché pour acheter et vendre des datasets climatiques.
- **Predictions** : Alertes et analyses prédictives alimentées par l'IA.
- **EcoNFT** : Certification de données comme actifs uniques sur la blockchain.

# File Description Inventory
- **app/backend/** : Fichiers de l'API backend, incluant la configuration et les modèles de données.
- **app/frontend/** : Fichiers de l'interface utilisateur, incluant les composants React et les styles.
- **app/frontend/index.html** : Fichier HTML principal avec le script Pi SDK.
- **app/frontend/src/lib/pi-sdk.ts** : Intégration du SDK Pi Network v2.0, mise à jour pour un chargement paresseux.
- **app/frontend/src/lib/api.ts** : Service API pour la communication entre le frontend et le backend, mis à jour pour une initialisation paresseuse.
- **app/frontend/src/lib/i18n.ts** : Gestion de l'internationalisation pour six langues, renommée pour correspondre au projet.
- **app/frontend/src/lib/eco-data.ts** : Données et logique pour les fonctionnalités environnementales d'EcoChain.
- **app/frontend/src/pages/** : Pages de l'application, y compris les nouvelles pages pour l'administration, la documentation, et les fonctionnalités d'EcoChain.
- **app/frontend/src/components/** : Composants réutilisables, y compris les notifications, le système de commentaires, et l'assistant IA.
- **app/frontend/public/sw.js** : Service Worker pour la gestion du cache.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, framer-motion pour les animations.
- **IA** : Intégration d'Atomes Cloud pour l'assistance IA.
- **Pi Network** : Intégration des fonctionnalités du SDK Pi Network v2.0.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
