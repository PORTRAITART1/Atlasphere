# Project Summary
Atlasphere is a decentralized governance super-app for Pi Network Pioneers that lets the community propose, vote, and fund local initiatives using token-driven coordination, supported by an impact dashboard (climate-focused tracking) and gamified quests to mobilize participation.

# Project Module Description
- Frontend (React/Vite): delivers the user experience for governance (proposal/voting/comment flows), community engagement (quests/rewards), user profile, and the marketing/branding assets consumed by the app UI.
- Backend (FastAPI): provides APIs for authentication, database models/migrations, and domain services related to Pi validation and Pi/payment flow orchestration.
- Pi Validation (backend): serves Pi Network validation key endpoints (raw text behavior, no SPA).
- Decentralized storage (IPFS): stores referenced content via CIDs where applicable.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Frontend: React, TypeScript, Tailwind CSS, Vite
- Pi Network: Pi Network SDK (v2.0)
- Storage/Assets: public marketing assets (PNG) for the frontend

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
pnpm run lint
```
