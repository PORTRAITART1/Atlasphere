# Project Summary
Le projet **PiSenate** est une plateforme de gouvernance décentralisée qui permet aux utilisateurs de soumettre des propositions pour financement. Grâce à un assistant IA intégré via Atoms Cloud, l'application facilite la rédaction des propositions en proposant des améliorations basées sur des projets similaires. PiSenate favorise la collaboration et l'innovation tout en respectant les normes de Pi Network, PiRC2, SDK et smart contracts.

# Project Module Description
Le projet est divisé en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission et la gestion des propositions.
- **Assistant IA** : Fournit des suggestions en temps réel pour améliorer les propositions.

# File Description Inventory
- **app/backend/** : Contient tous les fichiers relatifs à l'API backend, y compris la configuration de la base de données et les modèles de données.
- **app/frontend/** : Contient les fichiers de l'interface utilisateur, y compris les composants React, les pages et les configurations de style.
- **app/frontend/public/assets/logo-pipolis.jpeg** : Nouveau logo de l'application intégré dans la barre de navigation.
- **app/start_app_v2.sh** : Script pour démarrer l'application.
- **app/frontend/image_manifest.json** : Fichier de configuration pour les images utilisées dans l'application.
- **app/frontend/src/components/Navbar.tsx** : Composant de la barre de navigation, mis à jour pour afficher le nouveau logo.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS.
- **IA** : Intégration d'Atomes Cloud pour les fonctionnalités d'assistance IA.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
