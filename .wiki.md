# Project Summary

Atlasphere est une plateforme communautaire consacrée aux projets de l’écosystème Pi Network. Les Pioneers peuvent découvrir des initiatives, les financer en Pi, participer à leur gouvernance et échanger avec la communauté.

Les cinq projets sont localisés selon la langue sélectionnée et disposent de budgets compris entre 500 et 15 000 Pi. Chaque fiche présente trois jalons avec un titre, une description et un statut : « À venir », « En cours » ou « Terminé ».

Les votes « Pour » et « Contre » ainsi que les actions de discussion sont protégés par une authentification liée à l’identité Pi. Le JWT Atlasphere reste prioritaire ; si son échange échoue, les routes concernées peuvent vérifier directement le jeton Pi côté serveur. Le profil Pioneer est alors créé ou actualisé pour enregistrer le vote ou le commentaire.

Les paiements utilisent le wallet Pi et sont finalisés côté serveur. Le parcours attend la complétion réelle du paiement avant d’afficher un succès ; les annulations et erreurs sont remontées à l’utilisateur. Les contributions de financement de 10, 50 et 100 Pi ouvrent le wallet Pi. Les paiements de financement, de test, d’abonnement et Premium utilisent des montants et métadonnées adaptés au Mainnet.

L’interface prend en charge dix langues. La couverture reste partielle pour certaines pages et certains contenus backend ; consulter `I18N_AUDIT.md`.

`PI_API_KEY` doit rester côté backend et être fournie par un gestionnaire de secrets. `OIDC_CLIENT_ID` est réservé à Atoms/OIDC.

# Project Module Description

- **Projets** : découverte, suivi et financement des initiatives, avec contenus localisés et budgets révisés.
- **Jalons** : affichage de trois étapes par projet avec titre, description et statut.
- **Financement** : contributions en Pi par le wallet, finalisation serveur, gestion des annulations et erreurs, et reprise des paiements incomplets.
- **Abonnements et Premium** : paiements par wallet avec montants et métadonnées valides.
- **Gouvernance** : propositions et votes « Pour » ou « Contre », avec JWT Atlasphere prioritaire et vérification du jeton Pi en repli.
- **Discussions** : lecture et publication de commentaires, mentions « J’aime » et suppression soumise aux contrôles d’accès.
- **Authentification** : connexion Pi Network, échange de jeton Pi contre un JWT Atlasphere et gestion de session.
- **Profils et communauté** : profils, messagerie et notifications.
- **Avis des Pioneers** : notes et commentaires sur `/feedback`.
- **Quêtes et réputation** : progression, badges, parrainage et réputation.
- **Fonctionnalités d’écosystème** : assistant IA, API d’écosystème, NFT, prédictions, carte et analyses.
- **Internationalisation** : moteur i18n, dictionnaires et localisation des projets ; consulter `I18N_AUDIT.md`.
- **Tests, administration et conformité** : outils de test, configuration des administrateurs et pages juridiques localisées.
- **Documentation et marketing** : guides, feuille de route et ressources téléchargeables.

# Technology Stack

- **Frontend** : React, TypeScript, Vite
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy, Alembic
- **Authentification** : Pi SDK côté client ; JWT Atlasphere prioritaire et vérification directe du jeton Pi pour les routes concernées
- **Paiements** : Pi SDK côté frontend et API Pi Platform côté serveur ; complétion vérifiée avant confirmation de succès
- **Client HTTP** : HTTPX
- **Internationalisation** : moteur i18n et dictionnaires multilingues
- **Dépendances** : pnpm/npm et pip
- **Secrets** : gestionnaire de secrets pour `PI_API_KEY`

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via un gestionnaire de secrets ; ne pas l’exposer dans le frontend ni dans le dépôt. `OIDC_CLIENT_ID` concerne uniquement Atoms/OIDC.

Configurer les variables frontend nécessaires, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs. Utiliser Mainnet pour les paiements réels et Testnet/Sandbox pour les essais.

## Installer les dépendances

```bash
cd app/frontend
pnpm install
```

```bash
pip install -r requirements.txt
```

## Démarrer et vérifier

Depuis la racine du projet :

```bash
bash app/start_app_v2.sh
```

Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Pour valider un paiement réel, utiliser Pi Browser via l’App Viewer et vérifier l’approbation du wallet ainsi que la finalisation côté serveur. Le succès ne doit être affiché qu’après cette finalisation ; tester également l’annulation, les erreurs et la reprise des paiements incomplets. Les corrections de paiement ont passé les validations backend, lint, build et vérifications d’affichage.

Pour vérifier l’authentification, tester dans Pi Browser l’échange du jeton Pi, puis les votes et les actions de commentaires. Pour vérifier les traductions, changer la langue et consulter l’accueil, la liste et les fiches de projet. Consulter `I18N_AUDIT.md` pour les traductions encore incomplètes.
