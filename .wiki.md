# Project Summary
Atlasphere is a decentralized governance super-app for Pi Network Pioneers that lets the community propose, vote, and fund local initiatives, with a climate-focused impact dashboard and gamified quests to drive participation, including an internationalized EcoWallet experience to show eco-impact progress across multiple languages.

# Project Module Description
- Frontend (React/Vite): Governance UI (proposals, voting, comments), community engagement (quests/rewards), user profile, marketing/landing content, and EcoWallet with i18n-ready dynamic messaging.
- Backend (FastAPI): API for authentication, data models/migrations, and domain services coordinating Pi validation and Pi/payment-related flows.
- Pi Validation (backend): Provides Pi Network validation key endpoints as raw text for frontend consumption.
- Static assets/content: Frontend public assets (branding/marketing) and the validation key served as raw text.

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Frontend: React, TypeScript, Tailwind CSS, Vite, pnpm
- Pi Network: Pi Network SDK (v2.0)
- Assets/Content: Frontend public assets (marketing/branding and validation-key)

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
pnpm run lint
```
