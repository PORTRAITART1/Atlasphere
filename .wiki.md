# Project Summary
Le projet **PiSenate** est une plateforme de gouvernance décentralisée qui permet aux utilisateurs de soumettre des propositions pour financement. Grâce à un assistant IA intégré via Atoms Cloud, l'application facilite la rédaction des propositions en proposant des améliorations basées sur des projets similaires. PiSenate favorise la collaboration et l'innovation tout en respectant les normes de Pi Network, PiRC2, SDK et smart contracts. La plateforme intègre également des fonctionnalités avancées de génération de texte et d'images pour enrichir les propositions des utilisateurs, ainsi que des animations fluides pour améliorer l'expérience utilisateur.

# Project Module Description
Le projet est divisé en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission et la gestion des propositions. Comprend des fonctionnalités de génération d'images et de texte, ainsi que des animations fluides.
- **Assistant IA** : Fournit des suggestions en temps réel pour améliorer les propositions.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, framer-motion pour les animations.
- **IA** : Intégration d'Atomes Cloud pour les fonctionnalités d'assistance IA, incluant la génération de texte et d'images.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
