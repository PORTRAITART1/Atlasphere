# Project Summary
Atlasphere is a decentralized governance and funding platform for Pi Network Pioneers. Users can submit, discuss, vote on, and fund community projects while earning participation rewards and tracking ecological impact through EcoChain and EcoWallet. The application now supports seven ordered languages, localized project content, Russian translations, and improved navigation.

# Project Module Description
- **Governance and projects:** Browse, search, filter, vote on, comment on, and fund proposals. Ten multilingual project proposals are available, including PiRemit, PiCredit, PiVault, and PiGrid.
- **Internationalization:** Supports English, Arabic, Chinese, Russian, French, Portuguese, and Spanish in this order. English is the fallback language; Arabic supports RTL display.
- **Localized project data:** Project titles, descriptions, full details, statuses, categories, and reusable milestones resolve through the active locale.
- **Navigation:** Navbar includes responsive mega-menus for EcoChain, DAO, and additional features, with keyboard navigation, Escape-to-close behavior, mobile collapsible sections, active-page indicators, and quick filtering.
- **EcoChain and EcoWallet:** Provides ecological dashboards, rewards, environmental projects, carbon tracking, and translated EcoWallet content.
- **Pi integration:** Supports Pi authentication, voting, contributions, payment flows, and validation-key access.
- **Backend API:** FastAPI services expose project, authentication, governance, payment, and Pi validation APIs. Backend project data is available for local/mock environments.
- **Engagement:** Includes quests, rewards, badges, reputation, profiles, messaging, referrals, delegation, and community participation.

# File Description Inventory
- `app/backend/mock_data/projects.json`: Mock/backend project dataset for displaying proposals.
- `app/backend/routers/pi_validation.py`: Serves Pi Network validation endpoints.
- `app/frontend/src/components/Navbar.tsx`: Implements desktop mega-menus, mobile navigation sections, filtering, accessibility behavior, and localized labels.
- `app/frontend/src/lib/api.ts`: Retrieves and localizes project content, categories, statuses, and milestones.
- `app/frontend/src/lib/i18n.ts`: Initializes translations, language ordering, locale selection, fallback behavior, and RTL handling.
- `app/frontend/src/lib/store.ts`: Defines proposal models, ten project records, reusable milestone keys, project filters, statistics, votes, and contributions.
- `app/frontend/src/lib/locales/content.ts`: Central multilingual catalog for ten projects and shared milestone labels in English, Arabic, Chinese, Russian, French, Portuguese, and Spanish.
- `app/frontend/src/lib/locales/ru.ts`: Russian translations for navigation, governance, dashboard, EcoWallet, authentication, legal content, and common UI.
- `app/frontend/src/lib/eco-data.ts`: EcoWallet dynamic data and translation-key mappings.
- `app/frontend/src/pages/EcoWallet.tsx`: EcoWallet impact and reward interface.
- `app/frontend/src/pages/ValidationKey.tsx`: Displays or consumes the Pi validation key.
- `app/frontend/src/pages/UserProfile.tsx`: User profile and participation information.
- `app/frontend/public/validation-key.txt`: Raw Pi Network validation key.
- `app/frontend/public/_redirects`: SPA routing and deployment exceptions.
- `app/frontend/public/_headers`: Deployment header rules.
- `app/frontend/public/marketing-pack/`: Reusable branding and promotional assets.

# Technology Stack
- **Backend:** Python, FastAPI, SQLAlchemy, Alembic
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Package manager:** pnpm
- **Pi Network:** Pi Network SDK v2.0
- **Internationalization:** TypeScript locale dictionaries with runtime translation and fallback
- **Data:** JSON mock data, backend API, local proposal store
- **Deployment support:** SPA redirects, custom headers, AWS/Lambda handler

# Usage
Install backend dependencies:
```bash
cd app/backend
pip install -r requirements.txt
```

Install frontend dependencies:
```bash
cd app/frontend
pnpm install
```

Run checks and build the frontend:
```bash
pnpm run lint
pnpm run build
```

Run the backend according to the project instructions in `app/backend/README.md`.
