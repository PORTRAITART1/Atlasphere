# Project Summary
Atlasphere is a decentralized Pi Network super-app that lets Pioneers propose, vote, and fund local initiatives through community governance and tokens, with a climate-focused dashboard and gamified quests to track impact and mobilize the community.

# Project Module Description
- Backend (FastAPI): exposes APIs, handles authentication, DB models and migrations (Alembic), and provides services for Pi validation and Pi-related payment/flow orchestration.
- Frontend (React/Vite): provides governance flows (proposals, delegation, comments), engagement journeys (rewards, quests), an EcoWallet-style portfolio experience, plus marketing content.
- Pi Validation: serves a raw text key resource for Pi Network validation (no SPA behavior).
- Decentralized Storage (IPFS): integration to store files and reference them via CIDs.

# File Description Inventory
- app/backend/requirements.default / app/backend/requirements.txt : backend dependency lists.
- app/frontend/public/validation-key.txt : Pi Network validation key served as raw text.
- app/frontend/public/.well-known/test.txt : public test file.
- app/frontend/public/_redirects : SPA routing and exception rules.
- app/frontend/public/_headers : headers for specific control needs.
- app/backend/routers/pi_validation.py : Pi validation API endpoints.
- app/frontend/src/pages/ValidationKey.tsx : page that displays/consumes the validation key.
- app/frontend/src/pages/UserProfile.tsx : user profile page (stats display, logout, avatar upload).
- app/frontend/src/lib/i18n.ts : translation dictionaries and i18n initialization (now with English default and cleaned duplicate keys).

# Technology Stack
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Frontend: React, TypeScript, Tailwind CSS, Vite
- Pi Network: Pi Network SDK (v2.0) for payments/validation
- IA: Atoms Cloud
- Utilities: JSZip, file-saver

# Usage

```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
```
