# Project Summary
Atlasphere est une super-application décentralisée sur Pi Network qui permet aux Pioneers de proposer, voter et financer des initiatives locales via la gouvernance communautaire et des tokens, avec un tableau de bord climat et des quêtes gamifiées pour suivre l’impact et engager la communauté autour d’actions environnementales.

# Project Module Description
- **Backend (FastAPI)** : API, authentification, modèles et migrations (Alembic), services (dont la validation Pi) et gestion des paiements/flux liés à Pi.
- **Frontend (React/Vite)** : interface de gouvernance (propositions, délégation, commentaires), engagement (récompenses, quêtes) et écosystème (EcoWallet, partenaires, referral) ainsi que l’interface marketing.
- **Validation Pi (côté frontend/deployment)** : rendu d’une page dédiée à `/validation-key.txt` pour afficher la clé de validation en texte brut.
- **EcoWallet & i18n** : gestion portefeuille Pi/ECO et internationalisation de l’interface.
- **Stockage décentralisé (IPFS)** : intégration pour stocker des fichiers et indexer via CID.

# File Description Inventory
- **app/backend/requirements.default** / **app/backend/requirements.txt** : dépendances backend.
- **app/frontend/public/validation-key.txt** : ressource de validation exposée côté public.
- **app/frontend/public/.well-known/test.txt** : fichier de test.
- **app/frontend/public/_redirects** : règles de routage SPA et exceptions.
- **app/frontend/public/_headers** : headers pour contrôles spécifiques de réponse.
- **app/backend/routers/pi_validation.py** : endpoint backend permettant la validation via API.
- **app/frontend/src/pages/ValidationKey.tsx** : page React dédiée à l’affichage en texte brut de la clé de validation.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, Vite.
- **IA** : intégration Atoms Cloud.
- **Pi Network** : SDK Pi Network (v2.0) pour paiements/validation.
- **Outils** : JSZip, file-saver.

# Usage
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
pnpm run build
```
