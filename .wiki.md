# Project Summary
Le projet **Atlasphere** est une super-application décentralisée sur Pi Network, axée sur la gouvernance décentralisée, le financement participatif, et l'intelligence artificielle environnementale. Atlasphere permet aux utilisateurs, appelés Pioneers, de soumettre des propositions, voter sur des projets communautaires, et soutenir des initiatives locales avec des tokens Pi. Les utilisateurs interagissent dans un écosystème EcoChain AI pour surveiller le climat, gagner des tokens ECO, et réduire leur empreinte carbone. La plateforme propose des quêtes gamifiées, une messagerie communautaire, un tableau de bord climatique, et des ressources marketing, tout en intégrant un système de traduction complet pour une accessibilité multilingue.

# Project Module Description
Le projet est structuré en plusieurs modules fonctionnels :
- **Backend** : API, authentification, base de données, intégration de l'assistant IA, avec un endpoint pour la validation de domaine et la gestion des paiements Pi.
- **Frontend** : Interface utilisateur pour la gestion des propositions et interactions communautaires, avec des pages pour la clé de validation et le bouton de paiement Pi.
- **Assistant IA** : Suggestions en temps réel.
- **Système de Quêtes** : Gestion des quêtes et des récompenses.
- **Abonnements** : Gestion des abonnements premium.
- **Système de Commentaires** : Discussions sur les propositions.
- **Documentation API** : Détails sur les endpoints de l'API.
- **EcoWallet** : Gestion du portefeuille Pi + ECO, entièrement internationalisé.
- **Climate Dashboard** : Tableau de bord climatique avec données en temps réel.
- **EcoMarket** : Place de marché pour des datasets climatiques et crédits carbone.
- **Predictions** : Alertes et analyses prédictives.
- **DAO Avancée** : Gouvernance quadratique et trésorerie communautaire.
- **Notifications Personnalisées** : Gestion des préférences de notification.
- **Tableau de Bord Personnalisable** : Interface pour sélectionner les informations à afficher.
- **Système de Récompenses** : Encourage l'engagement des utilisateurs.
- **Stockage Décentralisé IPFS** : Gestion de fichiers avec CID et statistiques.
- **Système de Parrainage** : Mécanisme de referral avec récompenses.
- **Partenariats avec ONG** : Collaboration avec des organisations environnementales.
- **Éco-Publicités** : Publicités opt-in pour gagner des ECO tokens.
- **Profil Utilisateur Enrichi** : Informations sur l'utilisateur et ses contributions.
- **Téléchargement Marketing** : Page pour télécharger les ressources marketing en ZIP.

# File Description Inventory
- **app/backend/** : API backend, incluant la configuration, les modèles de données, et un endpoint pour la validation de domaine.
- **app/frontend/** : Interface utilisateur, incluant les composants React et les styles, avec une page pour afficher la clé de validation et un bouton de paiement Pi.
- **app/frontend/index.html** : Fichier HTML principal avec le script Pi SDK.
- **app/frontend/src/pages/** : Pages de l'application, y compris celles pour l'administration, la création de propositions, la délégation, le stockage IPFS, le parrainage, les partenaires, les éco-publicités, les paramètres, le profil utilisateur enrichi, la page de téléchargement marketing, et EcoWallet, ainsi qu'une nouvelle page pour la clé de validation.
- **app/frontend/src/components/** : Composants réutilisables, y compris la barre de navigation, le pied de page, le sélecteur de langue, et le bouton de paiement Pi.
- **app/frontend/src/lib/pi-sdk.ts** : Gestion des paiements Pi, incluant la reprise de paiement incomplet et les récentes mises à jour pour l'alignement avec la documentation officielle de Pi SDK.
- **app/frontend/src/lib/i18n.ts** : Gestion des traductions et des langues pour l'application, avec l'ajout des clés pour EcoWallet. La langue par défaut est maintenant l'anglais.
- **app/frontend/public/docs/** : Contient des documents marketing et des feuilles de route pour le lancement sur le Mainnet, ainsi que le pack marketing contenant des images et des bannières avec le logo Atlasphere.
- **app/frontend/public/_redirects** : Fichier mis à jour pour gérer le routage SPA sur l'hébergement statique, incluant une exception pour servir `validation-key.txt`.
- **app/frontend/public/validation-key.txt** : Fichier de validation pour la vérification du domaine Pi, contenant une clé essentielle.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, JSZip, file-saver.
- **IA** : Intégration des services d'Atomes Cloud pour l'assistance IA.
- **Pi Network** : Intégration du SDK Pi Network v2.0.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
