# Project Summary

Atlasphere est une plateforme communautaire dédiée aux projets de l’écosystème Pi Network. Les Pioneers peuvent découvrir et financer des initiatives en Pi, participer à leur gouvernance et échanger avec la communauté.

Les cinq projets sont localisés selon la langue sélectionnée et disposent de budgets compris entre 500 et 15 000 Pi. Chacun présente désormais trois jalons avec un titre, une description et un statut : « À venir », « En cours » ou « Terminé ».

Sur les fiches projet, les votes « Pour » et « Contre » sont enregistrés par une API authentifiée. L’identité du votant est vérifiée côté serveur, les compteurs sont mis à jour après le vote et un second vote sur le même projet est refusé.

Les discussions de projet prennent en charge la lecture et la publication de commentaires, les mentions « J’aime » et la suppression sécurisée. Les mutations vérifient l’authentification et les droits de propriété.

L’interface prend en charge dix langues. La couverture reste partielle pour certaines pages et certains contenus backend ; consulter `I18N_AUDIT.md`.

Les paiements Pi suivent un parcours User-to-App. `PI_API_KEY` doit rester côté backend et être fournie par un gestionnaire de secrets. `OIDC_CLIENT_ID` est réservé à Atoms/OIDC.

# Project Module Description

- **Projets** : découverte, suivi et financement des initiatives, avec contenus localisés et budgets révisés.
- **Jalons** : affichage, sur les fiches projet, de trois étapes par projet avec titre, description et statut.
- **Gouvernance** : propositions et votes « Pour » ou « Contre », avec authentification, prévention des doublons et mise à jour des compteurs.
- **Discussions** : lecture et publication de commentaires, mentions « J’aime » et suppression soumise aux contrôles d’accès.
- **Paiements Pi** : approbation dans le wallet et finalisation côté serveur.
- **Authentification** : connexion Pi Network et gestion de session.
- **Profils et communauté** : profils, messagerie et notifications.
- **Avis des Pioneers** : notes et commentaires sur `/feedback`.
- **Quêtes et réputation** : progression, badges, parrainage et réputation.
- **Fonctionnalités d’écosystème** : assistant IA, API d’écosystème, NFT, prédictions, carte et analyses.
- **Internationalisation** : moteur i18n, dictionnaires et localisation des projets ; consulter `I18N_AUDIT.md`.
- **Tests, administration et conformité** : outils de test, configuration des administrateurs et pages juridiques localisées.
- **Documentation et marketing** : guides, feuille de route et ressources téléchargeables.

# Technology Stack

- **Frontend** : React, TypeScript, Vite
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy, Alembic
- **Paiements** : Pi SDK côté frontend et API Pi Platform côté serveur
- **Client HTTP** : HTTPX
- **Internationalisation** : moteur i18n et dictionnaires multilingues
- **Dépendances** : pnpm/npm et pip
- **Secrets** : gestionnaire de secrets pour `PI_API_KEY`

# Usage

## Configuration

Fournir `PI_API_KEY` au backend via un gestionnaire de secrets ; ne pas l’exposer dans le frontend ni dans le dépôt. `OIDC_CLIENT_ID` concerne uniquement Atoms/OIDC.

Configurer les variables frontend nécessaires, notamment `VITE_ADMIN_USERNAMES` pour les comptes administrateurs. Utiliser Mainnet pour les paiements réels et Testnet/Sandbox pour les essais.

## Installer les dépendances

```bash
cd app/frontend
pnpm install
```

```bash
pip install -r requirements.txt
```

## Démarrer et vérifier

Depuis la racine du projet :

```bash
bash app/start_app_v2.sh
```

Appliquer les migrations lorsque la base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

Vérifier et compiler le frontend :

```bash
cd app/frontend
pnpm run lint
pnpm run build
```

Pour vérifier les traductions, changer la langue et consulter l’accueil, la liste et les fiches de projet. Les jalons et les commandes de vote sont accessibles depuis une fiche projet. Consulter `I18N_AUDIT.md` pour les traductions encore incomplètes.
