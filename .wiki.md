# Project Summary
Le projet **Polis** est une plateforme de gouvernance décentralisée qui permet aux utilisateurs de soumettre des propositions pour financement tout en intégrant des fonctionnalités avancées d'assistance via l'IA. Utilisant Atoms Cloud, l'application facilite la rédaction et l'amélioration des propositions, favorisant ainsi la collaboration et l'innovation au sein de la communauté Pi Network. Polis se conforme aux normes de Pi Network, PiRC2, SDK et smart contracts, tout en offrant une expérience utilisateur enrichie avec des animations fluides et des outils de génération de contenu.

# Project Module Description
Le projet est divisé en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données, et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission, et la gestion des propositions, incluant des fonctionnalités de génération d'images et de texte, ainsi que des animations.
- **Assistant IA** : Fournit des suggestions en temps réel pour améliorer les propositions.
- **Système de Quêtes** : Gère les quêtes et les récompenses pour les utilisateurs, y compris le suivi des progrès et la réclamation des récompenses.

# File Description Inventory
- **app/backend/** : Fichiers relatifs à l'API backend, y compris la configuration de la base de données et les modèles de données.
- **app/frontend/** : Fichiers de l'interface utilisateur, y compris les composants React et les styles.
- **app/frontend/src/lib/pi-sdk.ts** : Intégration du SDK Pi Network v2.0, gérant l'authentification et les paiements.
- **app/frontend/src/lib/i18n.ts** : Gestion de l'internationalisation pour 5 langues.
- **app/frontend/src/pages/Quests.tsx** : Page dédiée à la gestion des quêtes et récompenses.
- **app/frontend/src/components/Navbar.tsx** : Composant de navigation mis à jour pour inclure le sélecteur de langue et les nouvelles routes.
- **app/frontend/src/components/LanguageSelector.tsx** : Composant pour sélectionner la langue de l'interface utilisateur.
- **app/frontend/src/components/PiPaymentButton.tsx** : Bouton pour effectuer des paiements en Pi.
- **app/start_app_v2.sh** : Script pour démarrer l'application.
- **app/frontend/src/components/AIAssistant.tsx** : Composant pour l'assistant IA.
- **app/frontend/src/components/Footer.tsx** : Composant de pied de page mis à jour.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, framer-motion pour les animations.
- **IA** : Intégration d'Atomes Cloud pour l'assistance IA, incluant la génération de texte et d'images.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
