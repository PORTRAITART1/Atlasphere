# Project Summary

Atlasphere est une plateforme de découverte et de financement de projets. Elle permet aux utilisateurs de consulter des projets, de contribuer financièrement et désormais d’effectuer de vrais paiements en Pi Network depuis Pi Browser. Le flux de paiement est conçu pour répondre aux exigences de Pi Developer et suivre la progression vers cinq testeurs distincts.

# Project Module Description

- **Paiements Pi Network**
  - Paiements User-to-App en quatre étapes : création dans Pi Browser, approbation serveur, signature dans le portefeuille Pi et complétion serveur.
  - Vérification serveur du montant, du bénéficiaire, de la direction, du réseau, du paiement et du txid.
  - Clé `PI_API_KEY` conservée uniquement côté backend.
- **Registre des paiements**
  - Suivi des approbations, complétions, annulations et erreurs.
  - Idempotence par `payment_id` et prévention des crédits en double.
  - Historique limité au compte Atlasphere authentifié.
- **Financement de projets**
  - Crédit des projets uniquement après confirmation Pi Network.
  - Enregistrement des contributions et passage automatique au statut financé selon le budget.
- **Testeurs Pi Developer**
  - Page `/payment-test` avec montants de test de 0,1, 0,5 et 1 Pi.
  - Compteur des testeurs distincts, progression vers cinq utilisateurs et liste anonymisée.
  - Historique personnel des paiements.
- **Interface multilingue**
  - Libellés de paiement ajoutés en arabe, anglais, espagnol, français, portugais, russe et chinois.
- **Accès et navigation**
  - Route de paiement ajoutée à l’application et au menu principal.
  - Registre générique rendu accessible uniquement en lecture et avec authentification.

# Technology Stack

- **Frontend** : React, TypeScript, Vite, Tailwind CSS
- **Backend** : Python, FastAPI, Pydantic
- **Base de données** : SQLAlchemy asynchrone, Alembic
- **Paiements** : Pi Network SDK côté frontend et Pi Platform API côté serveur
- **Client HTTP** : HTTPX
- **Internationalisation** : moteur i18n interne multilingue
- **Validation** : compilation Python, lint frontend et build de production

# Usage

## Variables d’environnement

Configurer côté serveur :

```bash
PI_API_KEY=<clé serveur Pi Network>
```

La clé ne doit jamais être exposée au frontend.

## Backend

Installer les dépendances selon la configuration existante du projet, puis lancer le backend avec la commande habituelle de l’application.

Vérifier la syntaxe des modules de paiement :

```bash
cd app/backend
python -m py_compile \
  models/pi_payments.py \
  services/pi_payments.py \
  services/pi_payment_ledger.py \
  services/pi_platform.py \
  routers/pi_pay.py \
  routers/pi_payments.py
```

Appliquer les migrations avec Alembic lorsque l’environnement de base de données est disponible :

```bash
cd app/backend
alembic upgrade head
```

## Frontend

```bash
cd app/frontend
pnpm install
pnpm run lint
pnpm run build
```

Les paiements réels doivent être testés dans Pi Browser avec des comptes Pioneer distincts. Les paiements simulés ou sandbox ne valident pas l’exigence Pi Developer.
