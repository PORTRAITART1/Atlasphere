# Project Summary
Le projet **PoliGov** est une plateforme de gouvernance décentralisée qui permet aux utilisateurs de soumettre des propositions pour financement. En intégrant des fonctionnalités d'intelligence artificielle, PoliGov facilite la rédaction et l'amélioration des propositions, favorisant ainsi la collaboration au sein de la communauté Pi Network. L'application offre une expérience utilisateur enrichie avec des animations fluides et des outils de génération de contenu, tout en respectant les normes de Pi Network. PoliGov prend en charge six langues (FR, EN, ES, PT, ZH, AR) et propose un système de commentaires et des intégrations sociales pour partager des propositions. Les nouvelles fonctionnalités incluent la **Documentation API**, la **Sécurité & Transparence**, ainsi que des optimisations de performance comme le chargement paresseux et la possibilité de gérer des délégations de votes.

# Project Module Description
Le projet est divisé en plusieurs modules fonctionnels :
- **Backend** : Gère l'API, l'authentification, la base de données, et l'intégration de l'assistant IA.
- **Frontend** : Interface utilisateur pour la création, la soumission, et la gestion des propositions, incluant des fonctionnalités de génération d'images et de texte, ainsi que des animations.
- **Assistant IA** : Fournit des suggestions en temps réel pour améliorer les propositions.
- **Système de Quêtes** : Gère les quêtes et les récompenses pour les utilisateurs.
- **Abonnements** : Gestion des abonnements récurrents avec différents plans tarifaires.
- **Pages Légales** : Inclut la Politique de Confidentialité et les Conditions d'Utilisation.
- **Système de Commentaires** : Permet aux utilisateurs de discuter sur les propositions.
- **Documentation API** : Détails sur les endpoints de l'API, les types de requêtes, et les meilleures pratiques.
- **Sécurité & Transparence** : Informations sur les mesures de sécurité et la transparence des opérations.
- **Délégation de Votes** : Permet aux utilisateurs de déléguer leur poids de vote à d'autres utilisateurs.

# File Description Inventory
- **app/backend/** : Fichiers relatifs à l'API backend, y compris la configuration de la base de données et les modèles de données.
- **app/frontend/** : Fichiers de l'interface utilisateur, y compris les composants React et les styles.
- **app/frontend/index.html** : Fichier HTML principal, maintenant avec le script du Pi SDK pour l'authentification et les métadonnées PWA.
- **app/frontend/src/lib/pi-sdk.ts** : Intégration du SDK Pi Network v2.0, gérant l'authentification et les paiements.
- **app/frontend/src/lib/api.ts** : Service API pour connecter le frontend au backend réel.
- **app/frontend/src/lib/i18n.ts** : Gestion de l'internationalisation pour 6 langues.
- **app/frontend/src/pages/** : Pages de l'application, y compris les nouvelles pages pour l'administration, la délégation, l'analytique et la carte des projets.
- **app/frontend/src/components/** : Composants réutilisables, y compris les notifications, le système de commentaires et la recherche globale.

# Technology Stack
- **Backend** : Python, FastAPI, SQLAlchemy, Alembic.
- **Frontend** : React, TypeScript, Tailwind CSS, framer-motion pour les animations.
- **IA** : Intégration d'Atomes Cloud pour l'assistance IA, incluant la génération de texte et d'images.
- **Pi Network** : Intégration des dernières fonctionnalités du SDK Pi Network v2.0.

# Usage
Pour installer les dépendances, exécutez les commandes suivantes :
```bash
cd app/backend
pip install -r requirements.txt

cd app/frontend
pnpm install
```
Pour construire et exécuter l'application, utilisez :
```bash
cd app/frontend
pnpm run build
```
